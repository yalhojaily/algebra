<Callout type="why">
A triangle's three angles, three numbers with three clues, money split among three accounts: each clue becomes an equation. Many of these systems are simpler than they look, because some clues involve only two of the unknowns — and then substitution does most of the work.
</Callout>

## The plan

Use the five steps from 8.4, with one addition in the **Translate** step: write **one equation per clue**, and notice which equations already give one unknown in terms of another (like $B = A + 7$). Substitute those into the remaining equation first.

## Triangle angles

The angles of a triangle add up to $180°$ — that is always one of the equations, even though the problem may not say it.

<StepReveal
  client:visible
  title="Three angles"
  problem="In triangle $ABC$, angle $B$ is $7°$ more than angle $A$, and angle $C$ is $18°$ more than three times angle $A$. Find the angles."
  steps={[
    { show: '**Familiarize.** $A$, $B$, $C$ = the angles in degrees. Both $B$ and $C$ are described using $A$.', why: 'Guess $A = 30$: $B = 37$, $C = 108$, total $175$ — just short of $180$, so $A$ is a bit more than $30$.' },
    { show: '**Translate.** $\\;\\begin{cases} A + B + C = 180 \\\\ B = A + 7 \\\\ C = 3A + 18 \\end{cases}$', why: 'One equation per fact, plus the angle sum.' },
    { show: '**Solve.** $A + (A + 7) + (3A + 18) = 180 \\;\\Rightarrow\\; 5A + 25 = 180 \\;\\Rightarrow\\; A = 31$', why: 'Substitute $B$ and $C$ into the first equation: only $A$ is left.' },
    { show: '**Check.** $B = 38$, $C = 3(31) + 18 = 111$, and $31 + 38 + 111 = 180$ ✓', why: '' },
    { show: '**State.** The angles are $A = 31°$, $B = 38°$ and $C = 111°$.', why: '' },
  ]}
/>

  client:visible

## Three numbers

<StepReveal
  client:visible
  title="Three clues"
  problem="The sum of three numbers is $26$. The second number is twice the first, and the third is $6$ more than the first. Find the numbers."
  steps={[
    { show: '**Familiarize.** $x$, $y$, $z$ = the first, second and third numbers.', why: 'Both $y$ and $z$ are described using $x$ — substitution will be quick.' },
    { show: '**Translate.** $\\;\\begin{cases} x + y + z = 26 \\\\ y = 2x \\\\ z = x + 6 \\end{cases}$', why: '"6 more than the first" is $x + 6$, so $z = x + 6$ (not $x = z + 6$).' },
    { show: '**Solve.** $x + 2x + (x + 6) = 26 \\;\\Rightarrow\\; 4x = 20 \\;\\Rightarrow\\; x = 5$, so $y = 10$, $z = 11$', why: '' },
    { show: '**Check.** $5 + 10 + 11 = 26$ ✓; $10 = 2 \\cdot 5$ ✓; $11 = 5 + 6$ ✓', why: '' },
    { show: '**State.** The numbers are $5$, $10$ and $11$.', why: '' },
  ]}
/>

## Investments

With simple interest for one year, the interest is $I = Pr$: principal times rate. Write the rate as a decimal: $4\%$ of $x$ dollars is $0.04x$.

<StepReveal
  client:visible
  title="Three accounts"
  problem="$11{,}000$ dollars is invested in three accounts paying $3\%$, $4\%$ and $5\%$ simple interest. The total interest after one year is $455$ dollars, and the amount at $5\%$ is $1000$ dollars more than the amount at $4\%$. How much is in each account?"
  steps={[
    { show: '**Familiarize.** $x$, $y$, $z$ = dollars at $3\\%$, $4\\%$ and $5\\%$.', why: 'Three facts: the total invested, the total interest, and the comparison.' },
    { show: '**Translate.** $\\;\\begin{cases} x + y + z = 11000 \\\\ 0.03x + 0.04y + 0.05z = 455 \\\\ z = y + 1000 \\end{cases}$', why: 'Multiply the interest equation by $100$ to clear decimals: $3x + 4y + 5z = 45500$.' },
    { show: '**Solve.** Substitute $z = y + 1000$: $\\;x + 2y = 10000$ and $3x + 9y = 40500$. From the first, $x = 10000 - 2y$; then $30000 - 6y + 9y = 40500$, so $y = 3500$.', why: 'Now it is a 2 × 2 system in $x$ and $y$.' },
    { show: '$x = 10000 - 7000 = 3000$, $\\;z = 3500 + 1000 = 4500$. **Check.** $3000 + 3500 + 4500 = 11000$ ✓; interest $90 + 140 + 225 = 455$ ✓', why: '' },
    { show: '**State.** $3000$ dollars at $3\\%$, $3500$ dollars at $4\\%$ and $4500$ dollars at $5\\%$.', why: '' },
  ]}
/>

<QuickCheck
  client:visible

## Common mistakes

<Callout type="warning" title="Forgetting the hidden equation">
Triangle problems usually give only two clues. The third equation, $A + B + C = 180$, is a fact about every triangle.
</Callout>

<Callout type="warning" title="Reversing “more than”">
"$C$ is $18$ more than three times $A$" is $C = 3A + 18$. Test it with a number: if $A = 10$, then $C$ should be $48$.
</Callout>

<Callout type="warning" title="Percent as a decimal">
$4\%$ is $0.04$, not $0.4$ or $4$. If you multiply the interest equation by $100$, multiply **every** term, including the total interest.
</Callout>

<Callout type="warning" title="Answering one unknown">
These problems usually ask for all three quantities. State all of them, with units.
</Callout>

## Summary

- One equation per clue — and for triangles, add $A + B + C = 180$.
- Equations that give one unknown in terms of another make substitution quick.
- Interest for one year: principal × rate, with the rate as a decimal; clear decimals by multiplying by $100$.
- Check every clue in the original problem.
