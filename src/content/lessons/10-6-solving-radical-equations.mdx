<Callout type="why">
In 10.1 you used $r = 2\sqrt{5L}$ to get a car's speed from its skid marks. Now turn the question around: how long would the skid marks be at 60 mph? The unknown $L$ is **under** the radical, so you need a way to undo a root. There is one — squaring — but it comes with a trap this lesson teaches you to spot.

## The principle of powers — and its trap

> If $a = b$, then $a^n = b^n$.

Squaring both sides is allowed, but it is a **one-way** step. The converse fails: $(-3)^2 = 3^2$ even though $-3 \ne 3$. Squaring can turn a false equation into a true one, so the squared equation may have solutions the original doesn't. These are **extraneous** solutions. That's why every answer must be checked in the **original** equation.

Cubing has no such trap: different numbers always have different cubes.

## One radical

1. **Isolate** the radical on one side.
2. **Square** (or cube) both sides.
3. **Solve** the resulting equation.
4. **Check** every answer in the original equation.

## Extraneous solutions

When the other side contains $x$, squaring gives a quadratic — and often one of its solutions is false.

<StepReveal
  client:visible
  title="Reject a false solution"
  problem="Solve: $\;\sqrt{x + 7} = x - 5$"
  steps={[
    { show: '$x + 7 = (x - 5)^2 = x^2 - 10x + 25$', why: 'The radical is isolated; square both sides. Square the whole right side as a binomial.' },
    { show: '$x^2 - 11x + 18 = 0 \\;\\Rightarrow\\; (x - 2)(x - 9) = 0$', why: 'Bring everything to one side and factor (Chapter 5).' },
    { show: '$x = 9$: $\\sqrt{16} = 4$ and $9 - 5 = 4$ ✓', why: 'Check in the **original** equation.' },
    { show: '$x = 2$: $\\sqrt{9} = 3$ but $2 - 5 = -3$ ✗', why: 'Squaring hid the sign: $3^2 = (-3)^2$. Reject $x = 2$.' },
    { show: 'The only solution is $x = 9$.', why: '' },
  ]}
/>

## Two radicals

If each side has one radical, squaring removes both: $\sqrt{3x - 4} = \sqrt{2x + 3}$ gives $3x - 4 = 2x + 3$, so $x = 7$. Check: both radicands are $17$ ✓.

If two radicals are on the **same** side, isolate one of them, square, and you'll be left with one radical — isolate it and square again.

<StepReveal
  client:visible
  title="Square twice"
  problem="Solve: $\;\sqrt{x - 3} + \sqrt{x + 5} = 4$"
  steps={[
    { show: '$\\sqrt{x + 5} = 4 - \\sqrt{x - 3}$', why: 'Isolate one radical.' },
    { show: '$x + 5 = 16 - 8\\sqrt{x - 3} + (x - 3)$', why: 'Square both sides. The right side is a binomial: $(4 - \\sqrt{x - 3})^2 = 16 - 8\\sqrt{x - 3} + (x - 3)$.' },
    { show: '$8\\sqrt{x - 3} = 8 \\;\\Rightarrow\\; \\sqrt{x - 3} = 1$', why: 'The $x$-terms cancel. Isolate the remaining radical.' },
    { show: '$x - 3 = 1 \\;\\Rightarrow\\; x = 4$', why: 'Square again.' },
    { show: 'Check: $\\sqrt{1} + \\sqrt{9} = 1 + 3 = 4$ ✓', why: '' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Squaring before isolating">
Squaring $\sqrt{x - 3} + 5$ as it stands gives $(x - 3) + 10\sqrt{x - 3} + 25$ — the radical doesn't go away. Get the radical alone **before** squaring.
</Callout>

<Callout type="warning" title="Squaring a binomial term by term">
$(x - 5)^2 = x^2 - 10x + 25$, not $x^2 + 25$, and $(4 - \sqrt{x - 3})^2$ has a middle term $-8\sqrt{x - 3}$.
</Callout>

<Callout type="warning" title="Skipping the check">
Squaring can create false solutions. In $\sqrt{x + 7} = x - 5$, $x = 2$ satisfies the squared equation but not the original.
</Callout>

## Summary

- Squaring both sides is allowed, but it can create **extraneous** solutions, because $a^2 = b^2$ doesn't mean $a = b$.
- Isolate the radical, raise both sides to the index, solve, and **check every answer in the original equation**.
- Two radicals on one side: isolate one, square, then isolate the other and square again.
- Cubing never creates extraneous solutions.
