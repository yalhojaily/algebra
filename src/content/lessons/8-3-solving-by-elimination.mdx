<Callout type="why">
Substitution gets messy when no variable has a coefficient of $1$ or $-1$ — you end up with fractions right away. **Elimination** (also called the addition method) avoids that: you combine whole equations so one variable vanishes. It is the method behind every computer system solver, and the one you'll use for three variables in 8.5.
</Callout>

## Why it is allowed

Two facts make elimination work:

1. **Adding equal things to equal things keeps them equal.** If $A = B$ and $C = D$, then $A + C = B + D$. At a solution both equations are true, so their sum is true too.
2. **Multiplying an equation by a nonzero number doesn't change its solutions.** $x + 3y = 7$ and $2x + 6y = 14$ describe the same line.

So you may multiply the equations by any nonzero numbers and add them. The trick is to choose the numbers so that one variable's coefficients become **opposites** — then that variable cancels.

## Decimals and fractions: clear them first

Multiply an equation by $10$, $100$ or the LCD to get whole-number coefficients. It's the same line, and the arithmetic is far easier.

<StepReveal
  client:visible
  title="Clear the decimals"
  problem="Solve: $\;\begin{cases} 0.2x + 0.3y = 1.3 \\ 0.5x - 0.1y = 0.7 \end{cases}$"
  steps={[
    { show: '$\\begin{cases} 2x + 3y = 13 \\\\ 5x - y = 7 \\end{cases}$', why: 'Multiply both equations by $10$.' },
    { show: '$15x - 3y = 21$', why: 'Multiply the second by $3$ to get $-3y$, the opposite of $3y$.' },
    { show: '$17x = 34 \\;\\Rightarrow\\; x = 2$', why: 'Add it to $2x + 3y = 13$.' },
    { show: '$5(2) - y = 7 \\;\\Rightarrow\\; y = 3$. Solution: $(2, 3)$', why: 'Check in the original: $0.2(2) + 0.3(3) = 1.3$ ✓ and $0.5(2) - 0.1(3) = 0.7$ ✓' },
  ]}
/>

## Special cases

As with substitution: if **both** variables cancel, look at what is left. $0 = 0$ (true) means **infinitely many solutions**; something like $0 = 7$ (false) means **no solution**.

<StepReveal
  client:visible
  title="Everything cancels"
  problem="Solve: $\;\begin{cases} 2x - 3y = 4 \\ -4x + 6y = -8 \end{cases}$"
  steps={[
    { show: '$4x - 6y = 8$', why: 'Multiply the first equation by $2$.' },
    { show: '$0 = 0$', why: 'Add it to the second: every term cancels and the result is true.' },
    { show: '**Infinitely many solutions** — the equations describe the same line.', why: 'The second equation is $-2$ times the first.' },
  ]}
/>

<Callout type="tip" title="Which method?">
Use **substitution** when a variable is already isolated or has coefficient $\pm 1$. Otherwise **elimination** is usually quicker. Both always give the same answer.
</Callout>

## In a real context

Two purchases of the same two items give two equations of the form *(number) × (price) + (number) × (price) = total*. Neither price is "already solved", so elimination is the natural method.

## Common mistakes

<Callout type="warning" title="Multiplying only part of an equation">
Multiplying $x + 3y = 7$ by $-2$ gives $-2x - 6y = -14$. Every term changes — including the right side. Forgetting the $7$ is the most common slip.
</Callout>

<Callout type="warning" title="Adding when the terms have the same sign">
$-6y$ and $-6y$ add to $-12y$; they don't cancel. You need **opposites** ($6y$ and $-6y$) — or subtract the equations instead of adding.
</Callout>

<Callout type="warning" title="Sign slips when subtracting equations">
If you subtract, subtract **every** term: $(2x + 3y) - (5x - y) = -3x + 4y$, not $-3x + 2y$.
</Callout>

<Callout type="warning" title="Forgetting the second variable">
After finding $x$, substitute back for $y$, and give the answer as an ordered pair.
</Callout>

## Summary

- Adding equations and multiplying an equation by a nonzero number keep the solutions the same.
- Multiply so one variable's coefficients are opposites, add, solve, substitute back, check.
- Clear decimals and fractions first.
- All variables cancel: $0 = 0$ → infinitely many solutions; $0 = 7$ → none.
- Substitution when a variable is isolated or has coefficient $\pm 1$; elimination otherwise.
