<Callout type="why">
Substitution gets messy when no variable has a coefficient of $1$ — you end up with fractions right away. **Elimination** (also called the addition method) avoids that: you add whole equations so one variable vanishes.
</Callout>

## Adding equations

If $A = B$ and $C = D$, then $A + C = B + D$. When the coefficients of one variable are **opposites**, adding the equations eliminates it.

## Special cases

As with substitution: if **both** variables cancel, $0 = 0$ means infinitely many solutions and $0 = 7$ (false) means no solution.

<Practice client:visible lesson="8.3" skill="special" compact />

<Callout type="tip" title="Which method?">
Use substitution when a variable is already isolated or has coefficient $\pm 1$. Otherwise elimination is usually quicker.
</Callout>

## Summary

- Make one variable's coefficients opposites (multiply if needed), then add.
- Solve, substitute back, check.
