## Equations, solutions, and equivalent equations

A **solution** of an equation is a replacement for the variable that makes the equation true. To **solve** an equation means to find **all** its solutions.

The strategy is always the same: transform the equation, one step at a time, into an equation so simple that the solution is obvious, like $x = 541$. Each step must produce an **equivalent equation** — one with exactly the same solutions as before.

Remember the balance from Lesson 1.1: a value is a solution exactly when both sides weigh the same.

## The addition principle

If a balance is level and you add the same weight to **both** pans, it stays level. Taking the same weight off both pans keeps it level too.

<Callout type="definition" title="The addition principle for equations">
For any real numbers $a$, $b$, and $c$:

$$a = b \quad\text{is equivalent to}\quad a + c = b + c$$

You may add (or subtract) the **same number on both sides** of an equation, and the solutions don't change.
</Callout>

To get $x$ alone, add the **opposite** of the number that is added to $x$. That number and its opposite make $0$, and $x + 0 = x$.

<StepReveal
  client:visible

  problem="Solve: $\;-6.5 = y - 8.4$"

## Simplify first

If one side has numbers that can be combined, combine them before you solve.

## Watch out for these

<Callout type="warning" title="Common mistakes">
1. **Using the same operation instead of the opposite.** For $x + 5 = 12$, **subtract** $5$; don't add it.
2. **Changing only one side.** Whatever you do to one side, do to the other.
3. **Skipping the check.** Substitute your answer into the original equation — it takes seconds and catches sign errors.
</Callout>

## Summary

- To **solve** an equation is to find all values that make it true.
- **Addition principle:** $a = b$ is equivalent to $a + c = b + c$.
- To undo "$+\,c$", add $-c$ to both sides; to undo "$-\,c$", add $c$.
- Always check in the **original** equation.
