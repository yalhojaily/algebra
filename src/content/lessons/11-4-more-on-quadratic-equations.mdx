## The discriminant

In the quadratic formula, everything hinges on the part under the root:

$$x = \frac{-b \pm \sqrt{\boxed{b^2 - 4ac}}}{2a}$$

$b^2 - 4ac$ is called the **discriminant**. If it is positive, $\pm$ gives two different real numbers. If it is zero, $+0$ and $-0$ give the same number. If it is negative, the root is imaginary.

| $b^2 - 4ac$ | Solutions | Graph of $y = ax^2 + bx + c$ |
|---|---|---|
| positive | two real (rational if it is a perfect square) | crosses the $x$-axis twice |
| zero | one real (repeated) | touches the $x$-axis at the vertex |
| negative | two complex conjugates | doesn't reach the $x$-axis |

## Writing equations from solutions

The principle of zero products works backwards: if the solutions are $r$ and $s$, then $(x - r)(x - s) = 0$ has exactly those solutions. Multiply it out.

<StepReveal
  client:visible
  title="Build the equation"
  problem="Write a quadratic equation with the given solutions: (a) $3$ and $-5$; (b) $\tfrac{2}{3}$ and $1$; (c) $\pm\sqrt{3}$; (d) $\pm 2i$."
  steps={[
    { show: '(a) $(x - 3)(x + 5) = 0 \\;\\Rightarrow\\; x^2 + 2x - 15 = 0$', why: 'Subtracting $-5$ gives $+5$.' },
    { show: '(b) $(3x - 2)(x - 1) = 0 \\;\\Rightarrow\\; 3x^2 - 5x + 2 = 0$', why: '$x = \\frac{2}{3}$ gives $3x - 2 = 0$ — clearing the fraction.' },
    { show: '(c) $(x - \\sqrt{3})(x + \\sqrt{3}) = 0 \\;\\Rightarrow\\; x^2 - 3 = 0$', why: 'Difference of squares.' },
    { show: '(d) $(x - 2i)(x + 2i) = 0 \\;\\Rightarrow\\; x^2 + 4 = 0$', why: '$-(2i)^2 = -4i^2 = 4$.' },
  ]}
/>

## Equations quadratic in form

An equation is **quadratic in form** if a substitution $u = (\text{something})$ makes it $au^2 + bu + c = 0$. The test: one part is the **square** of another part ($x^4 = (x^2)^2$, $x = (\sqrt{x})^2$).

<StepReveal
  client:visible
  title="Let u = x²"
  problem="Solve: $\;x^4 - 13x^2 + 36 = 0$"
  steps={[
    { show: '$u^2 - 13u + 36 = 0$', why: 'Let $u = x^2$, so $x^4 = u^2$.' },
    { show: '$(u - 4)(u - 9) = 0 \\;\\Rightarrow\\; u = 4$ or $u = 9$', why: '' },
    { show: '$x^2 = 4$ or $x^2 = 9$, so $x = \\pm 2$ or $x = \\pm 3$', why: 'Go back to $x$ — four solutions, as a 4th-degree equation can have.' },
  ]}
/>

<StepReveal
  client:visible
  title="Let u = √x, and check"
  problem="Solve: $\;x - 3\sqrt{x} - 4 = 0$"
  steps={[
    { show: '$u^2 - 3u - 4 = 0$', why: 'Let $u = \\sqrt{x}$, so $x = u^2$.' },
    { show: '$(u - 4)(u + 1) = 0 \\;\\Rightarrow\\; u = 4$ or $u = -1$', why: '' },
    { show: '$\\sqrt{x} = 4 \\Rightarrow x = 16$; $\\;\\sqrt{x} = -1$ is impossible', why: 'A principal square root is never negative, so reject $u = -1$.' },
    { show: 'Solution: $x = 16$. Check: $16 - 3(4) - 4 = 0$ ✓', why: '' },
  ]}
/>

<StepReveal
  client:visible
  title="Substitute an expression"
  problem="Solve: $\;(x^2 - 1)^2 - 5(x^2 - 1) + 4 = 0$"
  steps={[
    { show: '$u^2 - 5u + 4 = 0$ with $u = x^2 - 1$', why: 'The whole block $x^2 - 1$ appears squared and plain.' },
    { show: '$(u - 1)(u - 4) = 0 \\;\\Rightarrow\\; u = 1$ or $u = 4$', why: '' },
    { show: '$x^2 - 1 = 1 \\Rightarrow x = \\pm\\sqrt{2}$; $\\;x^2 - 1 = 4 \\Rightarrow x = \\pm\\sqrt{5}$', why: 'Substitute back and solve each.' },
  ]}
/>

## In a real context

"Does it ever happen?" questions are discriminant questions: setting the quantity equal to the target gives a quadratic, and it has real solutions only if $b^2 - 4ac \ge 0$.

<StepReveal
  client:visible
  title="Does the ball get that high?"
  problem="A ball's height is $h(t) = -16t^2 + 64t + 4$ feet. Does it ever reach $80$ ft? What about $60$ ft?"
  steps={[
    { show: '**Translate.** $-16t^2 + 64t + 4 = 80 \\;\\Rightarrow\\; -16t^2 + 64t - 76 = 0$', why: 'Standard form.' },
    { show: '**Solve.** $b^2 - 4ac = 64^2 - 4(-16)(-76) = 4096 - 4864 = -768 < 0$', why: 'No real $t$: the ball never reaches $80$ ft.' },
    { show: 'For $60$ ft: $-16t^2 + 64t - 56 = 0$, and $4096 - 3584 = 512 > 0$', why: 'Two real times — once going up, once coming down.' },
    { show: '**Check.** The highest point is at $t = 2$: $h(2) = 68$ ft, between $60$ and $80$ ✓', why: '' },
    { show: '**State.** It reaches $60$ ft (twice) but never $80$ ft.', why: '' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Sign slips in b² − 4ac">
With $a = -16$ and $c = -76$, $-4ac = -4(-16)(-76) = -4864$. Write every factor in parentheses.
</Callout>

<Callout type="warning" title="Stopping at u">
In $x^4 - 13x^2 + 36 = 0$, $u = 4$ and $u = 9$ are not the answers. Substitute back: $x^2 = 4$ and $x^2 = 9$ give four values of $x$.
</Callout>

<Callout type="warning" title="Accepting a negative √x">
If $u = \sqrt{x}$, then $u = -1$ is impossible. Check every solution in the original equation.
</Callout>

## Summary

- The discriminant $b^2 - 4ac$ is under the root in the formula: positive → two real, zero → one real, negative → two complex. A perfect square means rational solutions (the equation factors).
- Solutions $r$ and $s$ → $(x - r)(x - s) = 0$.
- If one part of an equation is the square of another, substitute $u$ for it, solve, then substitute back and check.
- "Does it ever reach…?" → is the discriminant $\ge 0$?
