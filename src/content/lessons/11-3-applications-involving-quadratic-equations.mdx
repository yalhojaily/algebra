<Callout type="why">
Gravity, area and travel time all produce squares: falling distance grows with the **square** of time, area is length **times** width, and time = distance ÷ speed leads to a quadratic as soon as two speeds are involved. With factoring and the quadratic formula you can now solve all of them — and the extra step that matters most is deciding which solutions make sense.
</Callout>

## The plan

Use the five steps from 2.6. In the **Translate** step, expect a quadratic equation: write it in standard form, then solve by factoring (if it factors) or by the formula. In the **Check** step, reject any solution that is impossible in the situation — a negative time, length or speed.

## Falling and thrown objects

An object dropped from rest falls $s = 16t^2$ feet in $t$ seconds (about $4.9t^2$ meters). One thrown upward from height $h_0$ at $v$ ft/s has height $h(t) = -16t^2 + vt + h_0$.

<ProjectileLab client:visible />

<StepReveal
  client:visible
  title="Dropped"
  problem="A stone is dropped from a bridge $400$ ft above the water. How long does it take to hit the water?"
  steps={[
    { show: '**Translate.** $16t^2 = 400$', why: 'Distance fallen $= 400$ ft.' },
    { show: '**Solve.** $t^2 = 25 \\;\\Rightarrow\\; t = \\pm 5$', why: 'Principle of square roots.' },
    { show: '**Check & state.** Time is positive, so $t = 5$: it hits the water after $5$ seconds.', why: '$16 \\cdot 25 = 400$ ✓.' },
  ]}
/>

<StepReveal
  client:visible
  title="Thrown up from a roof"
  problem="A ball is thrown upward from a $48$-ft roof at $32$ ft/s: $h(t) = -16t^2 + 32t + 48$. When does it hit the ground?"
  steps={[
    { show: '**Translate.** $-16t^2 + 32t + 48 = 0$', why: 'On the ground, the height is $0$.' },
    { show: '**Solve.** $t^2 - 2t - 3 = 0 \\;\\Rightarrow\\; (t - 3)(t + 1) = 0$', why: 'Divide by $-16$ first: smaller numbers.' },
    { show: '**Check.** $t = -1$ is before the throw — reject it. $h(3) = -144 + 96 + 48 = 0$ ✓', why: '' },
    { show: '**State.** The ball lands after $3$ seconds.', why: '' },
  ]}
/>

## Solving formulas

To solve a formula for a squared variable: isolate the square, then take the **positive** square root when the variable is a length, a speed or a time.

<StepReveal
  client:visible
  title="Solve for r"
  problem="Solve $\;A = \pi r^2\;$ for $r$, and $\;V = \pi r^2 h\;$ for $r$."
  steps={[
    { show: '$r^2 = \\dfrac{A}{\\pi} \\;\\Rightarrow\\; r = \\sqrt{\\dfrac{A}{\\pi}}$', why: 'A radius is positive, so no $\\pm$.' },
    { show: '$r^2 = \\dfrac{V}{\\pi h} \\;\\Rightarrow\\; r = \\sqrt{\\dfrac{V}{\\pi h}}$', why: 'Divide by everything that multiplies $r^2$, then take the root.' },
  ]}
/>

## Area

<StepReveal
  client:visible
  title="A rectangle"
  problem="A rectangle is $4$ m longer than it is wide, and its area is $96$ m². Find its dimensions."
  steps={[
    { show: '**Familiarize.** $w$ = width, $w + 4$ = length.', why: '' },
    { show: '**Translate.** $w(w + 4) = 96 \\;\\Rightarrow\\; w^2 + 4w - 96 = 0$', why: '' },
    { show: '**Solve.** $(w + 12)(w - 8) = 0 \\;\\Rightarrow\\; w = 8$ (reject $-12$)', why: '' },
    { show: '**Check & state.** $8 \\times 12 = 96$ ✓. It is $8$ m wide and $12$ m long.', why: '' },
  ]}
/>

<StepReveal
  client:visible
  title="A border around a photo"
  problem="A $10$ cm by $8$ cm photo gets a frame of uniform width $x$. The framed picture has an area of $120$ cm². How wide is the frame?"
  steps={[
    { show: '**Familiarize.** The frame adds $x$ on **each** side, so the outer size is $(10 + 2x)$ by $(8 + 2x)$.', why: 'A sketch makes the $2x$ clear.' },
    { show: '**Translate.** $(10 + 2x)(8 + 2x) = 120$', why: '' },
    { show: '**Solve.** $4x^2 + 36x + 80 = 120 \\;\\Rightarrow\\; x^2 + 9x - 10 = 0 \\;\\Rightarrow\\; (x + 10)(x - 1) = 0$', why: 'Divide by $4$.' },
    { show: '**Check & state.** $x = 1$ (reject $-10$): $12 \\times 10 = 120$ ✓. The frame is $1$ cm wide.', why: '' },
  ]}
/>

## Motion with two speeds

Time = distance ÷ speed. When a trip has two parts at different speeds, adding the two times gives a rational equation that turns into a quadratic.

<StepReveal
  client:visible
  title="Two speeds"
  problem="A cyclist rides $60$ km, then $50$ km at a speed $5$ km/h faster. The whole trip takes $5$ hours. Find the first speed."
  steps={[
    { show: '**Familiarize.** Let $r$ = first speed (km/h); the second is $r + 5$.', why: 'Guess $r = 20$: $\\frac{60}{20} + \\frac{50}{25} = 3 + 2 = 5$ — a good guess!' },
    { show: '**Translate.** $\\dfrac{60}{r} + \\dfrac{50}{r + 5} = 5$', why: 'Time for each part, added.' },
    { show: '**Solve.** $60(r + 5) + 50r = 5r(r + 5) \\;\\Rightarrow\\; 5r^2 - 85r - 300 = 0 \\;\\Rightarrow\\; r^2 - 17r - 60 = 0$', why: 'Multiply by $r(r + 5)$, collect, divide by $5$.' },
    { show: '$(r - 20)(r + 3) = 0$, so $r = 20$ km/h', why: 'Reject $r = -3$: a speed is positive.' },
    { show: '**State.** The first speed was $20$ km/h (and the second $25$ km/h).', why: '' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Keeping impossible solutions">
Both solutions solve the equation, but negative times, lengths and speeds don't fit the situation. Say why you reject them.
</Callout>

<Callout type="warning" title="A border on one side only">
A uniform border of width $x$ adds $2x$ to each dimension.
</Callout>

<Callout type="warning" title="Time = speed ÷ distance">
It's the other way: time = distance ÷ speed. Check units: km ÷ (km/h) = h.
</Callout>

## Summary

- Translate to a quadratic, write it in standard form, solve by factoring or the formula.
- Falling: $s = 16t^2$ ft; thrown: $h(t) = -16t^2 + vt + h_0$; landing means $h = 0$.
- Solving formulas for a squared length: isolate the square, take the positive root.
- Always check each solution against the situation.
