## Falling and thrown objects

An object dropped from rest falls $s = 16t^2$ feet in $t$ seconds. One thrown upward from height $h_0$ at $v$ ft/s has height $h(t) = -16t^2 + vt + h_0$.

## Solving formulas

To solve $A = \pi r^2$ for $r$: isolate $r^2$, then take the **positive** square root (a radius can't be negative): $r = \sqrt{\dfrac{A}{\pi}}$.
