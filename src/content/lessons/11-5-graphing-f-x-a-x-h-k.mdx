<Callout type="why">
The path of a basketball, the cable of a suspension bridge and the cross-section of a satellite dish are all parabolas. In vertex form you can read the most important point — the top or bottom — directly from the equation.
</Callout>

## The effect of a, h and k

$$f(x) = a(x - h)^2 + k$$

- $a$: if $|a| > 1$ the graph is narrower, if $|a| < 1$ wider; if $a < 0$ it opens **down**.
- $h$: shifts the graph **right** $h$ units (left if $h < 0$).
- $k$: shifts the graph **up** $k$ units (down if $k < 0$).

<Callout type="warning" title="The sign of h">
$f(x) = (x + 3)^2$ is $(x - (-3))^2$: it moves **left** 3, and the vertex is $(-3, 0)$.
</Callout>

## Axis of symmetry and extreme values

The parabola is symmetric about the vertical line $x = h$. If $a > 0$, the vertex is the lowest point, so $k$ is the **minimum** value; if $a < 0$, $k$ is the **maximum** value.

## Summary

- Vertex $(h, k)$, axis $x = h$.
- $a > 0$: opens up, minimum $k$; $a < 0$: opens down, maximum $k$.
- $|a|$ controls the width.
