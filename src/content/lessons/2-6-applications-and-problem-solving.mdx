<Callout type="why">
You can now solve almost any linear equation. But a real problem doesn't arrive as an equation — it arrives as a paragraph. The hard part is **writing** the equation. This lesson gives you a method that works on problems you've never seen before.
</Callout>

## The five-step strategy

<Callout type="tip" title="Five steps for problem solving">
1. **Familiarize** yourself with the problem. Read it twice. Draw a picture. Make a guess and check it — even a wrong guess shows you how the numbers relate. Choose a letter for the unknown, and **write down what it means**.
2. **Translate** the problem into an equation.
3. **Solve** the equation.
4. **Check** the answer in the **original problem** (not just in your equation — the equation itself might be wrong).
5. **State** the answer clearly, in a complete sentence with units.
</Callout>

## Consecutive integers

**Consecutive integers** follow each other, like $16, 17, 18$: if the first is $x$, the next are $x + 1$ and $x + 2$. **Consecutive even** (or **odd**) integers are $2$ apart: $x$, $x + 2$, $x + 4$.

<StepReveal
  client:visible
  title="Consecutive odd integers"
  problem="The sum of two consecutive odd integers is $76$. Find the integers."
  steps={[
    { show: '**Familiarize.** Let $x$ = the first. The next odd integer is $x + 2$.', why: 'Odd numbers are $2$ apart, just like even numbers.' },
    { show: '**Translate.** $x + (x + 2) = 76$', why: '' },
    { show: '**Solve.** $2x + 2 = 76$, $\\;2x = 74$, $\\;x = 37$', why: '' },
    { show: '**Check.** $37$ and $39$ are consecutive odd integers, and $37 + 39 = 76$ ✓', why: '' },
    { show: '**State.** The integers are $37$ and $39$.', why: '' },
  ]}

## Watch out for these

<Callout type="warning" title="Common mistakes">
1. **Not saying what the variable means.** Write "Let $x$ = the shorter piece, in cm." It prevents answering the wrong question.
2. **Answering only part of the question.** If it asks for both pieces, give both.
3. **Checking in your equation only.** Check against the original words — your equation could be the thing that's wrong.
</Callout>

## Summary

- **Familiarize → Translate → Solve → Check → State.**
- Pick one variable and write every other unknown in terms of it.
- Consecutive integers: $x, x + 1, x + 2$. Consecutive even/odd: $x, x + 2, x + 4$.
- Triangle angles sum to $180^\circ$. Rectangle perimeter: $P = 2l + 2w$.
