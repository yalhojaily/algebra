<Callout type="why">
A calculator says "Error" when you divide by $0$ — that input is outside the **domain** of division. Knowing the domain tells you which inputs make sense before you start computing.
</Callout>

## Interval notation

| Interval | Means | Graph ends |
|---|---|---|
| $[a, b]$ | $a \le x \le b$ | both included (solid dots) |
| $(a, b)$ | $a < x < b$ | neither included (open dots) |
| $[a, b)$ | $a \le x < b$ | left included, right not |
| $[a, \infty)$ | $x \ge a$ | goes on forever to the right |
| $(-\infty, b)$ | $x < b$ | goes on forever to the left |
| $(-\infty, \infty)$ | all real numbers | |

$\infty$ is not a number you can reach, so it **always** gets a round parenthesis. To type an interval, write something like `[-3, 5)` or `(-inf, 2]`.

## Domain from a formula

When a function is given by a formula and nothing else is said, its domain is **every real number that makes the formula work**. So far, the only thing that can go wrong is **division by zero**.

- $f(x) = x^2 - 5x + 1$: domain is all real numbers.
- $g(x) = \dfrac{3}{x - 4}$: every real number **except** $4$.

## Common mistakes

<Callout type="warning" title="Mixing up domain and range">
Domain = inputs ($x$, horizontal). Range = outputs ($y$, vertical).
</Callout>

<Callout type="warning" title="A bracket at infinity">
$[3, \infty]$ is wrong: $\infty$ is never reached, so write $[3, \infty)$.
</Callout>

<Callout type="warning" title="Excluding the wrong values">
Only the **denominator** matters. In $\dfrac{x - 2}{x + 1}$, $x = 2$ is fine; $x = -1$ is excluded.
</Callout>

## Summary

- Domain = all inputs ($x$-values); range = all outputs ($y$-values).
- On a graph: domain is the shadow on the $x$-axis, range is the shadow on the $y$-axis.
- Brackets $[\ ]$ include an endpoint; parentheses $(\ )$ don't; $\infty$ always gets a parenthesis.
- From a formula: exclude values that make a denominator $0$.
