<Callout type="why">
$\dfrac{5x}{x + 1} - \dfrac{2x - 3}{x + 1}$ is **not** $\dfrac{3x - 3}{x + 1}$. The $-$ sign subtracts the *whole* numerator $2x - 3$, so the $-3$ becomes $+3$. This one sign error accounts for most wrong answers in this lesson.
</Callout>

## Same denominator

$$\frac{A}{C} - \frac{B}{C} = \frac{A - (B)}{C}$$

Put the second numerator in **parentheses** before you subtract.

<StepReveal
  client:visible
  title="Subtract the whole numerator"
  problem="Subtract: $\;\dfrac{5x}{x + 1} - \dfrac{2x - 3}{x + 1}$"
  steps={[
    { show: '$= \\dfrac{5x - (2x - 3)}{x + 1}$', why: 'Parentheses around the second numerator.' },
    { show: '$= \\dfrac{5x - 2x + 3}{x + 1}$', why: 'The minus sign changes **every** sign inside.' },
    { show: '$= \\dfrac{3x + 3}{x + 1} = \\dfrac{3(x + 1)}{x + 1} = 3$', why: 'Factor and cancel.' },
  ]}
/>

## Opposite denominators

Multiplying the second fraction by $\frac{-1}{-1}$ turns the subtraction into an addition:

$$\frac{x}{x - 5} - \frac{5}{5 - x} = \frac{x}{x - 5} + \frac{5}{x - 5} = \frac{x + 5}{x - 5}$$

## Adding and subtracting together

With three or more fractions, rewrite **all** of them with one LCD, then combine all the numerators at once.

<StepReveal
  client:visible

  steps={[

## Summary

- $\frac{A}{C} - \frac{B}{C} = \frac{A - (B)}{C}$ — subtract every term of $B$.
- Opposite denominators: subtracting becomes adding.
- Different denominators: factor → LCD → rewrite → combine → simplify.
