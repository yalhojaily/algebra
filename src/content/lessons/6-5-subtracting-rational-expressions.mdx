<Callout type="why">
$\dfrac{5x}{x + 1} - \dfrac{2x - 3}{x + 1}$ is **not** $\dfrac{3x - 3}{x + 1}$. The $-$ sign subtracts the *whole* numerator $2x - 3$, so the $-3$ becomes $+3$. This one sign error accounts for most wrong answers in this lesson.
</Callout>

## Same denominator

$$\frac{A}{C} - \frac{B}{C} = \frac{A - (B)}{C}$$

Put the second numerator in **parentheses** before you subtract.

<StepReveal
  client:visible
  title="Subtract the whole numerator"
  problem="Subtract: $\;\dfrac{5x}{x + 1} - \dfrac{2x - 3}{x + 1}$"
  steps={[
    { show: '$= \\dfrac{5x - (2x - 3)}{x + 1}$', why: 'Parentheses around the second numerator.' },
    { show: '$= \\dfrac{5x - 2x + 3}{x + 1}$', why: 'The minus sign changes **every** sign inside.' },
    { show: '$= \\dfrac{3x + 3}{x + 1} = \\dfrac{3(x + 1)}{x + 1} = 3$', why: 'Factor and cancel.' },
  ]}
/>

<QuickCheck
  client:visible
  question="Subtract: $\;\dfrac{4x}{x - 2} - \dfrac{x + 6}{x - 2}$"
  options={['$3$', '$\\dfrac{3x + 6}{x - 2}$', '$3x - 6$', '$\\dfrac{5x + 6}{x - 2}$']}
  answer={0}
  explain="$4x - (x + 6) = 3x - 6 = 3(x - 2)$, which cancels with the denominator."
  wrong={{ 1: 'The minus sign applies to the $6$ too: $4x - x - 6$.', 2: 'Keep the denominator — then $\\frac{3(x - 2)}{x - 2}$ simplifies.', 3: 'Subtract the second numerator; don\'t add it.' }}

## Opposite denominators

Multiplying the second fraction by $\frac{-1}{-1}$ turns the subtraction into an addition:

$$\frac{x}{x - 5} - \frac{5}{5 - x} = \frac{x}{x - 5} + \frac{5}{x - 5} = \frac{x + 5}{x - 5}$$

## Different denominators

The steps are the same as for adding: factor, find the LCD, rewrite each fraction, then subtract the numerators (with parentheses!) and simplify.

## Adding and subtracting together

With three or more fractions, rewrite **all** of them with one LCD, then combine all the numerators at once.

<StepReveal
  client:visible
  title="Three fractions"

  steps={[
    { show: 'LCD $= x(x - 1)$', why: '$x^2 - x = x(x - 1)$ already contains the other two denominators.' },

## Common mistakes

<Callout type="warning" title="Not subtracting every term">
$\dfrac{5x}{x + 1} - \dfrac{2x - 3}{x + 1} = \dfrac{5x - 2x + 3}{x + 1}$. Use parentheses around the second numerator.
</Callout>

<Callout type="warning" title="Opposite denominators">
$\dfrac{x}{x - 5} - \dfrac{5}{5 - x}$ becomes $\dfrac{x}{x - 5} + \dfrac{5}{x - 5}$: flipping the denominator flips the operation.
</Callout>

<Callout type="warning" title="Cancelling terms">
In $\dfrac{x^2 + x + 6}{(x - 3)(x + 3)}$ nothing cancels: $x^2 + x + 6$ has no factor $x - 3$ or $x + 3$.
</Callout>

## Summary

- $\frac{A}{C} - \frac{B}{C} = \frac{A - (B)}{C}$ — subtract every term of $B$.
- Opposite denominators: subtracting becomes adding.
- Different denominators: factor → LCD → rewrite → combine → simplify.
