<Callout type="why">
The equation $x^2 + 1 = 0$ has no real solution. Mathematicians invented a number $i$ with $i^2 = -1$ — and it turned out to be indispensable in electrical engineering, signal processing and quantum physics. In Chapter 11 it will let every quadratic equation have solutions.
</Callout>

## The number i

$$i = \sqrt{-1}, \qquad i^2 = -1$$

For $p > 0$: $\sqrt{-p} = i\sqrt{p}$. So $\sqrt{-49} = 7i$ and $\sqrt{-5} = i\sqrt{5}$.

A **complex number** has the form $a + bi$: $a$ is the **real part**, $b$ the **imaginary part**. Type answers like `3 - 2i`.

## Adding, subtracting, multiplying

Treat $i$ like a variable — then replace $i^2$ by $-1$.

<StepReveal
  client:visible
  title="Multiply"

    { show: '$= 11 + 10i$', why: '' },

<Callout type="warning" title="√a · √b needs care">
$\sqrt{-4}\cdot\sqrt{-9}$ is **not** $\sqrt{36} = 6$. Write each in terms of $i$ first: $2i \cdot 3i = 6i^2 = -6$.
</Callout>

## Powers of i

<ComplexPlane client:visible />

$i^1 = i,\ i^2 = -1,\ i^3 = -i,\ i^4 = 1$, then the pattern repeats. To simplify $i^n$, divide $n$ by $4$ and use the remainder.

<Practice client:visible lesson="10.8" skill="powers" compact />

## Dividing

The **conjugate** of $a + bi$ is $a - bi$, and $(a + bi)(a - bi) = a^2 + b^2$ — a real number. Multiply the top and bottom by the conjugate of the denominator:

<StepReveal
  client:visible
  title="Divide"
  problem="Divide: $\;\dfrac{5 + i}{1 - i}$"
  steps={[
    { show: '$= \\dfrac{(5 + i)(1 + i)}{(1 - i)(1 + i)}$', why: 'Multiply by the conjugate $1 + i$.' },
    { show: '$= \\dfrac{5 + 6i + i^2}{1 - i^2} = \\dfrac{4 + 6i}{2}$', why: '' },
    { show: '$= 2 + 3i$', why: '' },
  ]}
/>

## Summary

- $i = \sqrt{-1}$, $i^2 = -1$; $\sqrt{-p} = i\sqrt{p}$.
- Add/subtract real and imaginary parts separately; multiply with FOIL and $i^2 = -1$.
- Powers of $i$ cycle with period 4.
- Divide using the conjugate of the denominator.
