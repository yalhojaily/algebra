<Callout type="why">
How long is the side of a square with area 50 m²? How fast was a car going if it left 80-foot skid marks? How long does a stone take to fall 45 m? Each question runs squaring **backwards** — it needs a **root**. This lesson sets out exactly what the root symbols mean, where they make sense, and one surprise: $\sqrt{x^2}$ is not always $x$.
</Callout>

## Square roots

$c$ is a **square root** of $a$ if $c^2 = a$. Every positive number has **two** square roots: $5$ and $-5$ are both square roots of $25$. But a symbol must stand for **one** number, so $\sqrt{a}$ means the **principal** (nonnegative) square root:

$$\sqrt{25} = 5, \qquad -\sqrt{25} = -5, \qquad \sqrt{0} = 0.$$

$\sqrt{-25}$ is **not a real number**: every real number squared is $\ge 0$, so nothing squares to $-25$. (Lesson 10.8 builds new numbers for it.)

## Cube roots and other roots

$c$ is the **cube root** of $a$ if $c^3 = a$. A negative number cubed is negative, so every real number has exactly one real cube root, with the same sign: $\sqrt[3]{-8} = -2$ because $(-2)^3 = -8$.

The same pattern holds for any index $n$: **odd** roots ($\sqrt[3]{\ }$, $\sqrt[5]{\ }$, …) exist for every real number; **even** roots ($\sqrt{\ }$, $\sqrt[4]{\ }$, …) need a radicand $\ge 0$.

## Radical functions and their domains

A function like $f(x) = \sqrt{x + 2} + 1$ is a **radical function**. Because the radicand of a square root cannot be negative, its domain is restricted to the $x$-values that make the radicand $\ge 0$. Cube-root functions have no such restriction.

## Roots of powers: why √(a²) = |a|

For any real number $a$:

$$\sqrt{a^2} = |a| \qquad \sqrt[3]{a^3} = a$$

Try $a = -3$: $\sqrt{(-3)^2} = \sqrt{9} = 3$, not $-3$. Squaring erases the sign, and the principal root is never negative, so the result is the **absolute value**. Cube roots keep the sign, so $\sqrt[3]{(-3)^3} = \sqrt[3]{-27} = -3$ — no absolute value needed.

<StepReveal
  client:visible
  title="Simplify roots of powers"
  problem="Simplify, for any real values: $\;\sqrt{(x - 3)^2},\;\; \sqrt{16x^2},\;\; \sqrt[3]{-8y^3}$"
  steps={[
    { show: '$\\sqrt{(x - 3)^2} = |x - 3|$', why: '' },
    { show: '$\\sqrt{16x^2} = \\sqrt{(4x)^2} = |4x| = 4|x|$', why: '$4$ is already positive, so only $x$ needs the absolute value.' },
    { show: '$\\sqrt[3]{-8y^3} = \\sqrt[3]{(-2y)^3} = -2y$', why: 'An odd root: no absolute value.' },
  ]}
/>

Type absolute values as `|x|` or `abs(x)`.

## Common mistakes

<Callout type="warning" title="√(a²) = a">
Only when $a \ge 0$. In general $\sqrt{a^2} = |a|$: $\sqrt{(-3)^2} = 3$.
</Callout>

<Callout type="warning" title="√(−9) = −3">
No real number squares to $-9$, so $\sqrt{-9}$ is not real. But $-\sqrt{9} = -3$ is fine — the minus sign is outside.
</Callout>

<Callout type="warning" title="Forgetting that 0 is allowed">
The radicand must be **at least** $0$, not greater than $0$. The domain of $\sqrt{x - 3}$ is $[3, \infty)$, with a bracket.
</Callout>

<Callout type="warning" title="Splitting a sum">
$\sqrt{9 + 16} = \sqrt{25} = 5$, not $\sqrt{9} + \sqrt{16} = 7$. Roots do not distribute over addition.
</Callout>

## Summary

- $\sqrt{a}$ is the nonnegative square root; even roots of negative numbers are not real; odd roots exist for all real numbers.
- Domain of a square-root function: radicand $\ge 0$.
- $\sqrt{a^2} = |a|$ (squaring erases the sign), $\sqrt[3]{a^3} = a$.
- In applications, lengths and times take the principal (positive) root.
