## Absolute value as distance

$|a|$ is the distance from $a$ to $0$, and $|x - h|$ is the distance from $x$ to $h$. For $d > 0$:

| | means | solution |
|---|---|---|
| $\lvert X \rvert = d$ | $X = d$ or $X = -d$ | two points |
| $\lvert X \rvert < d$ | $-d < X < d$ | one interval |
| $\lvert X \rvert > d$ | $X < -d$ or $X > d$ | two pieces |

## Summary

- $|X| = d$: $X = \pm d$ (no solution if $d < 0$).
- $|X| < d$: $-d < X < d$ — "less than" gives one interval ("and").
- $|X| > d$: $X < -d$ or $X > d$ — "greater than" gives two pieces ("or").
