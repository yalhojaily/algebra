<Callout type="why">
A machine part must be $50$ mm long, give or take $0.2$ mm: $|L - 50| \le 0.2$. A poll's result is $52\%$ with a margin of error of $3$ points: $|s - 52| \le 3$. Absolute value is the natural language of **tolerance** — how far something is from a target — and each of these statements hides an "and" or an "or".
</Callout>

## Absolute value as distance

$|a|$ is the distance from $a$ to $0$, so it is never negative. More generally, $|x - h|$ is the **distance between $x$ and $h$**: $|7 - 4| = 3$ and $|1 - 4| = 3$, because $7$ and $1$ are both $3$ units from $4$.

Thinking in distances explains every rule in this lesson. For $d > 0$:

| | in words | means | solution |
|---|---|---|---|
| $\lvert X \rvert = d$ | exactly $d$ from $0$ | $X = d$ **or** $X = -d$ | two points |
| $\lvert X \rvert < d$ | less than $d$ from $0$ | $-d < X < d$ (an **and**) | one interval |
| $\lvert X \rvert > d$ | more than $d$ from $0$ | $X < -d$ **or** $X > d$ | two pieces |

When two absolute values are equal, $|A| = |B|$, the insides are the same distance from $0$, so they are equal or opposite: $A = B$ or $A = -B$.

## In a real context

"Within $d$ of a target $T$" is $|x - T| \le d$: one interval, from $T - d$ to $T + d$. "More than $d$ away" is $|x - T| > d$: two pieces.

  title="Machine tolerance"
  problem="A bolt must be $50$ mm long with a tolerance of $0.2$ mm: its length $x$ must satisfy $|x - 50| \le 0.2$. Which lengths are accepted?"

    { show: '**Familiarize.** $x$ = length in mm. Accepted lengths are close to $50$: within $0.2$.', why: 'A $50.1$ mm bolt is fine; a $50.3$ mm bolt is not.' },
    { show: '**Translate.** $-0.2 \\le x - 50 \\le 0.2$', why: '"Less than or equal" gives one interval.' },

    { show: '**Check.** $x = 50.2$: $|0.2| \\le 0.2$ ✓; $x = 50.3$: $|0.3| \\le 0.2$ ✗', why: '' },
    { show: '**State.** Bolts from $49.8$ mm to $50.2$ mm are accepted: $[49.8, 50.2]$.', why: '' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Splitting before isolating">
In $3|x + 1| - 2 = 10$, writing $3(x + 1) - 2 = \pm 10$ is wrong. Isolate first: $|x + 1| = 4$, then split.
</Callout>

<Callout type="warning" title="“Less than” written as “or”">
$|x - 4| < 3$ is **one** interval: $-3 < x - 4 < 3$. "Or" belongs to "greater than". Memory aid: *less than* → *between*; *greater than* → *outside*.
</Callout>

<Callout type="warning" title="Forgetting the negative case">
$|2x - 3| = 7$ has two solutions. Solving only $2x - 3 = 7$ loses $x = -2$.
</Callout>

<Callout type="warning" title="Solving |X| = −4 anyway">
If the isolated absolute value equals a negative number, stop: no solution. For $|X| > -4$, every number works.
</Callout>

## Summary

- $|x - h|$ is the distance between $x$ and $h$. Isolate the absolute value before splitting.
- $|X| = d$: $X = \pm d$; $|A| = |B|$: $A = B$ or $A = -B$.
- $|X| < d$: $-d < X < d$ (between); $|X| > d$: $X < -d$ or $X > d$ (outside).
- Negative right side: $|X| = -d$ and $|X| < -d$ have no solution; $|X| > -d$ is every real number.
- "Within $d$ of $T$" is $|x - T| \le d$.
