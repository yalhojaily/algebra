<Callout type="why">
A rectangle has area $x^2 + 7x + 10$ and width $x + 2$. How long is it? You need $(x^2 + 7x + 10) \div (x + 2)$. Polynomial division undoes multiplication — and it's the tool you'll use to check factoring in Chapter 5.
</Callout>

## Dividing by a monomial

Dividing is multiplying by the reciprocal, so the distributive law applies: divide **each term** of the polynomial by the monomial.

$$\frac{a + b}{c} = \frac{a}{c} + \frac{b}{c}$$

  client:visible
  title="Term by term"
  problem="Divide: $\;\dfrac{12x^4 - 8x^3 + 6x^2}{2x^2}$"

    { show: '$\\dfrac{12x^4}{2x^2} - \\dfrac{8x^3}{2x^2} + \\dfrac{6x^2}{2x^2}$', why: '' },

    { show: 'Check: $2x^2(6x^2 - 4x + 3) = 12x^4 - 8x^3 + 6x^2$ ✓', why: 'Multiply back.' },
  ]}
/>

## Long division by a binomial

The cycle is the same as long division with numbers:

1. **Divide** the first term of what's left by the first term of the divisor.
2. **Multiply** that result by the whole divisor.
3. **Subtract** (change all the signs!).
4. **Bring down** and repeat until the remainder has lower degree than the divisor.

<StepReveal
  client:visible
  title="No remainder"
  problem="Divide: $\;(x^2 + 7x + 10) \div (x + 2)$"
  steps={[
    { show: '**Divide:** $x^2 \\div x = x$', why: 'First term by first term.' },
    { show: '**Multiply:** $x(x + 2) = x^2 + 2x$. **Subtract:** $(x^2 + 7x) - (x^2 + 2x) = 5x$. Bring down $+10$: $5x + 10$', why: '' },
    { show: '**Divide:** $5x \\div x = 5$. **Multiply:** $5(x + 2) = 5x + 10$. **Subtract:** $0$', why: '' },
    { show: 'Quotient $x + 5$, remainder $0$. Check: $(x + 2)(x + 5) = x^2 + 7x + 10$ ✓', why: '' },
  ]}
/>

## Remainders

If the remainder isn't $0$, write the answer as $\;\text{quotient} + \dfrac{\text{remainder}}{\text{divisor}}$ — just as $17 \div 5 = 3 + \frac{2}{5}$.

<StepReveal
  client:visible
  title="With a remainder"
  problem="Divide: $\;(2x^2 + 3x - 4) \div (x - 1)$"
  steps={[
    { show: '$2x^2 \\div x = 2x$; $\\;2x(x - 1) = 2x^2 - 2x$; subtract: $5x - 4$', why: '$3x - (-2x) = 5x$.' },
    { show: '$5x \\div x = 5$; $\\;5(x - 1) = 5x - 5$; subtract: $1$', why: '$-4 - (-5) = 1$.' },
    { show: '$= 2x + 5 + \\dfrac{1}{x - 1}$', why: 'The remainder $1$ has degree $0$, lower than $x - 1$, so we stop.' },
    { show: 'Check: $(x - 1)(2x + 5) + 1 = 2x^2 + 3x - 5 + 1 = 2x^2 + 3x - 4$ ✓', why: 'divisor × quotient + remainder = dividend.' },
  ]}
/>

## Missing terms

If a power of $x$ is missing in the dividend, write it with a $0$ coefficient so the columns line up.

<QuickCheck
  client:visible
  question="Before dividing $\;x^3 - 8\;$ by $\;x - 2$, how should you write the dividend?"
  options={['$x^3 + 0x^2 + 0x - 8$', '$x^3 - 8$ is fine as it is', '$x^3 + 0x - 8$', '$x^2 - 8$']}
  answer={0}
  explain="Every power from $x^3$ down to the constant needs a place: $x^2$ and $x$ are missing, so give them $0$ coefficients."
  wrong={{ 1: 'Without placeholders the subtraction steps put unlike terms in the same column.', 2: 'The $x^2$ term is missing too.', 3: 'Don\'t change the dividend — just add $0$ placeholders.' }}
/>

<StepReveal
  client:visible
  title="Fill the gaps"
  problem="Divide: $\;(x^3 - 8) \div (x - 2)$"
  steps={[
    { show: '$x^3 + 0x^2 + 0x - 8$', why: 'Placeholders.' },

    { show: '$+4$: subtract $4x - 8$ → $0$', why: '' },

## Common mistakes

<Callout type="warning" title="Subtract every term">
After multiplying, subtract the **whole** product. In $(2x^2 + 3x) - (2x^2 - 2x)$ the result is $5x$, not $x$.
</Callout>

<Callout type="warning" title="Dividing only the first term">
$\frac{10x^3 - 4x}{2x}$ is $5x^2 - 2$, not $5x^2 - 4x$. Every term is divided.
</Callout>

<Callout type="warning" title="Skipping placeholders">
Without $0x^2$ and $0x$ in $x^3 - 8$, the columns slip and the answer goes wrong.
</Callout>

## Summary

- By a monomial: divide each term.
- By a binomial: divide, multiply, subtract, bring down — repeat.
- Answer with remainder: $Q + \frac{R}{\text{divisor}}$. Check: divisor × quotient + remainder = dividend.
- Fill in missing powers with $0$ coefficients.
