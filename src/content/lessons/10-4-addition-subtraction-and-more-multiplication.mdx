<Callout type="why">
$3\sqrt{2} + 5\sqrt{2}$ works exactly like $3x + 5x$: the answer is $8\sqrt{2}$. But $\sqrt{2} + \sqrt{3}$ is like $x + y$ — it doesn't combine. The trick is to simplify first, so you can see which radicals really are alike.
</Callout>

## Like radicals

**Like radicals** have the same index and the same radicand. Combine their coefficients:

$$7\sqrt{5} - 2\sqrt{5} = 5\sqrt{5}$$

<RadicalSteps client:visible set="combine" />

<Callout type="warning" title="Never add radicands">
$\sqrt{9} + \sqrt{16} = 3 + 4 = 7$, but $\sqrt{9 + 16} = \sqrt{25} = 5$. So $\sqrt{a} + \sqrt{b} \ne \sqrt{a + b}$.
</Callout>

## Conjugates

$\sqrt{a} + b$ and $\sqrt{a} - b$ are **conjugates**. Their product is a difference of squares, and the radical disappears:

$$(\sqrt{7} + 2)(\sqrt{7} - 2) = 7 - 4 = 3$$

You'll use this in 10.5 to clear radicals from denominators.

<Practice client:visible lesson="10.4" skill="conjugate" compact />

## Summary

- Simplify every radical first; then combine like radicals.
- Distribute and FOIL as usual; $\sqrt{a}\sqrt{a} = a$.
- Conjugates multiply to a rational number.
