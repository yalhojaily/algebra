<Callout type="why">
$3\sqrt{2} + 5\sqrt{2}$ works exactly like $3x + 5x$: the answer is $8\sqrt{2}$. But $\sqrt{2} + \sqrt{3}$ is like $x + y$ — it doesn't combine. Radical expressions follow the algebra of polynomials you already know; the only new step is to **simplify first**, so you can see which radicals really are alike.
</Callout>

## Like radicals — and why only they combine

**Like radicals** have the same index and the same radicand. They combine by the distributive law, exactly like like terms:

$$7\sqrt{5} - 2\sqrt{5} = (7 - 2)\sqrt{5} = 5\sqrt{5}$$

$\sqrt{2}$ and $\sqrt{3}$ are different numbers ($1.414\ldots$ and $1.732\ldots$), so $\sqrt{2} + \sqrt{3}$ can't be written as a single radical — just as $x + y$ can't be written as one term.

## Multiplying

Use the distributive law and FOIL exactly as with polynomials, and remember $\sqrt{a}\cdot\sqrt{a} = a$.

## Conjugates

$\sqrt{a} + b$ and $\sqrt{a} - b$ are **conjugates**. Their product is a difference of squares, $(A + B)(A - B) = A^2 - B^2$, so the radical disappears:

$$(\sqrt{7} + 2)(\sqrt{7} - 2) = 7 - 4 = 3 \qquad (\sqrt{5} + \sqrt{2})(\sqrt{5} - \sqrt{2}) = 5 - 2 = 3$$

The middle terms $-2\sqrt{7}$ and $+2\sqrt{7}$ cancel. You'll use this in 10.5 to clear radicals from denominators.

## Common mistakes

<Callout type="warning" title="Never add radicands">
$\sqrt{9} + \sqrt{16} = 3 + 4 = 7$, but $\sqrt{9 + 16} = \sqrt{25} = 5$. So $\sqrt{a} + \sqrt{b} \ne \sqrt{a + b}$.
</Callout>

<Callout type="warning" title="Combining unlike radicals">
$\sqrt{2} + \sqrt{3}$ is already simplified. Combine only after simplifying shows the same radicand.
</Callout>

<Callout type="warning" title="Losing the middle term">
$(\sqrt{5} + 1)^2 \neq 5 + 1$. Use FOIL or $(A + B)^2 = A^2 + 2AB + B^2$.
</Callout>

## Summary

- Simplify every radical first; then combine like radicals (same index, same radicand) by adding coefficients.
- Distribute and FOIL as with polynomials; $\sqrt{a}\sqrt{a} = a$.
- Conjugates multiply to a number with no radical: $(\sqrt{a} + b)(\sqrt{a} - b) = a - b^2$.
