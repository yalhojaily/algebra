## Fraction → decimal

A fraction bar means divide: $\frac{3}{8} = 3 \div 8 = 0.375$. If the denominator is a factor of 10, 100 or 1000, there's a shortcut: rename it.

<StepReveal
  client:visible
  title="Two ways"
  problem="Write $\dfrac{7}{20}$ as a decimal."
  steps={[
    { show: '$\\dfrac{7 \\cdot 5}{20 \\cdot 5} = \\dfrac{35}{100} = 0.35$', why: '$20 \\times 5 = 100$, so make the denominator 100. 35 hundredths is $0.35$.' },
    { show: '$7 \\div 20 = 0.35$', why: 'Long division (or a calculator) gives the same answer.' },
  ]}
/>

Some decimals never end. $\frac{1}{3} = 0.333\ldots$ **repeats**, so we write $0.\overline{3}$ or round it. A fraction in lowest terms gives a terminating decimal exactly when its denominator has no prime factors other than 2 and 5.

<StepReveal
  client:visible
  title="Repeating decimal"
  problem="Write $\dfrac{5}{6}$ as a decimal rounded to the nearest hundredth."
  steps={[
    { show: '$5 \\div 6 = 0.8333\\ldots$', why: '$6 = 2 \\cdot 3$ has a factor of 3, so the decimal repeats.' },
    { show: '$\\approx 0.83$', why: 'The thousandths digit is 3, which is less than 5, so round down.' },
  ]}
/>

## Decimal → fraction

Read the decimal by its last place value and write it as a fraction: $0.35$ is 35 *hundredths*, so $\frac{35}{100}$. Then reduce.

<StepReveal
  client:visible
  title="Decimal to fraction"
  problem="Write $0.875$ as a fraction in lowest terms."
  steps={[
    { show: '$0.875 = \\dfrac{875}{1000}$', why: 'Three decimal places means thousandths.' },
    { show: '$= \\dfrac{875 \\div 125}{1000 \\div 125} = \\dfrac{7}{8}$', why: 'The GCD of 875 and 1000 is 125.' },
  ]}
/>

For a decimal greater than 1, like $2.4 = \frac{24}{10} = \frac{12}{5}$, you can also write it as the mixed number $2\frac{2}{5}$.

## Decimals and percents

**Percent** means "per hundred": $n\% = \frac{n}{100}$.

- **Decimal → percent:** multiply by 100. Move the decimal point **two places right**: $0.375 = 37.5\%$.
- **Percent → decimal:** divide by 100. Move the decimal point **two places left**: $4.5\% = 0.045$.

<StepReveal
  client:visible
  title="Both directions"
  problem="Write $1.2$ as a percent, and $0.6\%$ as a decimal."
  steps={[
    { show: '$1.2 \\times 100 = 120$, so $1.2 = 120\\%$', why: 'More than 1 whole is more than 100%.' },
    { show: '$0.6 \\div 100 = 0.006$, so $0.6\\% = 0.006$', why: 'Less than 1% is less than one hundredth.' },
  ]}
/>

## Fractions and percents

- **Percent → fraction:** write over 100 and reduce: $35\% = \frac{35}{100} = \frac{7}{20}$.
- **Fraction → percent:** make the denominator 100 if you can. Otherwise, change to a decimal first and then multiply by 100.

<StepReveal

## Common mistakes

<Callout type="warning">
**Moving the decimal point the wrong way.** A percent is a *bigger-looking* number than its decimal: $0.25 = 25\%$, not $0.0025\%$. If you're unsure, check with $\frac{1}{2} = 0.5 = 50\%$.
</Callout>

<Callout type="warning">
**Treating the % sign as decoration.** $0.5\%$ is not $0.5$. It is half of one percent, $0.005$.
</Callout>

<Callout type="warning">
**Writing the digits over 100 no matter what.** $0.7 = \frac{7}{10}$, not $\frac{7}{100}$. The number of decimal places decides the denominator.
</Callout>

<Callout type="warning">
**Forgetting to reduce.** $0.35 = \frac{35}{100}$ is correct but not finished: $\frac{7}{20}$.
</Callout>

## Summary

- Fraction → decimal: divide the numerator by the denominator (round repeating decimals if asked).
- Decimal → fraction: write over 10, 100, 1000, … by place value, then reduce.
- Decimal → percent: × 100 (two places right). Percent → decimal: ÷ 100 (two places left).
- Percent → fraction: over 100, then reduce. Fraction → percent: via a denominator of 100 or via the decimal.
