## The substitution method

1. Solve one equation for one variable (pick a variable with coefficient $1$ or $-1$ if you can).
2. **Substitute** that expression into the **other** equation. Now it has only one variable.
3. Solve it.
4. Substitute back to find the other variable.
5. Check in both original equations.

## When the variable disappears

Sometimes both variables cancel:

- A **false** statement like $0 = 5$ means **no solution** (parallel lines).
- A **true** statement like $0 = 0$ means **infinitely many solutions** (the same line).

<Practice client:visible lesson="8.2" skill="special" compact />

## Summary

- Isolate → substitute into the other equation → solve → substitute back → check.
- False statement: no solution. True statement: infinitely many.
