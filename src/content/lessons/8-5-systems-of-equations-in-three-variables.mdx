## Ordered triples

A solution of a system in $x$, $y$ and $z$ is an **ordered triple** $(x, y, z)$ that makes **every** equation true. Type it with parentheses, like `(1, -2, 3)`.

  steps={[
    { show: '$1 + (-2) + 3 = 2$ ✓', why: '' },

    { show: '$1 + 2(-2) - 3 = -6$ ✓', why: '' },
    { show: 'Yes — all three equations are true.', why: '' },
  ]}

## Back-substitution

If the last equation has one variable and the middle one has two, the system is **triangular**: solve from the bottom up. Every method for three variables aims to reach this shape.

<StepReveal
  client:visible
  title="Back-substitution"
  problem="Solve: $\;\begin{cases} x + y - z = 2 \\ y + 2z = 7 \\ 3z = 9 \end{cases}$"
  steps={[
    { show: '$z = 3$', why: 'From the last equation.' },
    { show: '$y + 6 = 7 \\;\\Rightarrow\\; y = 1$', why: 'Substitute $z$ into the middle equation.' },
    { show: '$x + 1 - 3 = 2 \\;\\Rightarrow\\; x = 4$', why: 'Substitute both into the first.' },
    { show: 'Solution: $(4, 1, 3)$', why: '' },
  ]}
/>

## Elimination with three variables

The idea: **remove one variable twice.** Two equations in $x$ and $y$ are a system you already know how to solve.

1. Choose a variable to eliminate — the one that is easiest to cancel.
2. Use **two different pairs** of equations to eliminate it. You get two equations in the other two variables.
3. Solve that 2 × 2 system.
4. Substitute back to find the third variable.
5. Check in **all three** original equations.

<StepReveal
  client:visible
  title="Eliminate z twice"
  problem="Solve: $\;\begin{cases} x + y + z = 6 & (1) \\ 2x - y + z = 3 & (2) \\ x + 2y - z = 2 & (3) \end{cases}$"
  steps={[
    { show: '$(1) + (3)$: $\\;2x + 3y = 8$ $\\quad (A)$', why: '$z$ has opposite coefficients in (1) and (3), so add them.' },
    { show: '$(2) + (3)$: $\\;3x + y = 5$ $\\quad (B)$', why: 'A **different** pair, eliminating the **same** variable, $z$.' },
    { show: 'From (B): $y = 5 - 3x$. Into (A): $2x + 3(5 - 3x) = 8 \\;\\Rightarrow\\; -7x = -7 \\;\\Rightarrow\\; x = 1$', why: 'Now it is a 2 × 2 system; $y$ has coefficient $1$ in (B), so substitution is quick.' },
    { show: '$y = 5 - 3 = 2$, and from (1): $z = 6 - 1 - 2 = 3$', why: 'Back-substitute.' },
    { show: 'Solution: $(1, 2, 3)$', why: 'Check: $(2)$: $2 - 2 + 3 = 3$ ✓; $(3)$: $1 + 4 - 3 = 2$ ✓' },
  ]}
/>

## In a real context

Three unknown prices and three orders give three equations. Look for an equation that is missing a variable: it makes the elimination shorter.

<StepReveal
  client:visible
  title="Three drinks"
  problem="At a café, $1$ coffee, $1$ tea and $1$ juice cost $9$ dollars; $2$ coffees and $1$ tea cost $8$ dollars; $1$ coffee and $2$ juices cost $11$ dollars. Find the price of each drink."
  steps={[
    { show: '**Familiarize.** $c$, $t$, $j$ = prices of a coffee, a tea and a juice (dollars).', why: 'Three unknowns, three orders. Two of the orders are missing a drink — useful.' },
    { show: '**Translate.** $\\;\\begin{cases} c + t + j = 9 & (1) \\\\ 2c + t = 8 & (2) \\\\ c + 2j = 11 & (3) \\end{cases}$', why: '' },
    { show: '**Solve.** $(1) - (2)$: $-c + j = 1$, so $j = c + 1$. Into (3): $c + 2(c + 1) = 11 \\;\\Rightarrow\\; c = 3$. Then $j = 4$ and, from (2), $t = 8 - 6 = 2$.', why: 'Subtracting (2) from (1) eliminates $t$; now (3) and $j = c + 1$ are a 2 × 2 system.' },
    { show: '**Check.** $3 + 2 + 4 = 9$ ✓; $6 + 2 = 8$ ✓; $3 + 8 = 11$ ✓', why: '' },
    { show: '**State.** A coffee costs 3 dollars, a tea 2 dollars and a juice 4 dollars.', why: '' },
  ]}

## Common mistakes

<Callout type="warning" title="Eliminating different variables">
Both new equations must be missing the **same** variable. If one has only $x$ and $y$ and the other only $x$ and $z$, you haven't made progress.
</Callout>

<Callout type="warning" title="Using the same pair twice">
Combining (1) and (3) twice gives the same equation twice. The second elimination must use a different pair — and between the two pairs, all three equations must be used.
</Callout>

<Callout type="warning" title="Sign slips when subtracting equations">
$(1) - (2)$ means subtracting **every** term of (2): $(c + t + j) - (2c + t) = -c + j$, and $9 - 8 = 1$.
</Callout>

<Callout type="warning" title="Checking in only one equation">
A triple can satisfy one or two equations by accident. Check in all three originals.
</Callout>

## Summary

- Solutions are ordered triples $(x, y, z)$ that make all three equations true.
- A triangular system is solved from the bottom up.
- Eliminate the **same** variable from two different pairs → a 2 × 2 system → solve → back-substitute → check all three.
- In word problems, an equation missing a variable is a shortcut.
