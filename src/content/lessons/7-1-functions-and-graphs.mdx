<Callout type="why">
A vending machine is useful because pressing B4 always gives you the same snack. If B4 sometimes gave chips and sometimes gave water, you couldn't rely on it. A **function** is a rule you can rely on in exactly that way: each input gives one predictable output.
</Callout>

## What is a function?

A **function** is a correspondence between a first set, the **domain**, and a second set, the **range**, that assigns to each member of the domain **exactly one** member of the range.

- $\{(1, 4),\ (2, 7),\ (3, 4)\}$ **is** a function. Two inputs share the output $4$ — that's allowed.
- $\{(1, 4),\ (1, 5),\ (3, 2)\}$ is **not** a function. The input $1$ has two outputs.

## Function notation

We name functions with letters like $f$, $g$, $h$. The symbol $f(x)$ — read "$f$ of $x$" — means **the output of $f$ when the input is $x$**. It does *not* mean $f$ times $x$.

## Functions and their graphs

The graph of $f$ is the set of all points $(x, f(x))$. To find $f(a)$ from a graph, start at $a$ on the $x$-axis, go up or down to the graph, then across to the $y$-axis.

## The vertical-line test

If a vertical line crosses a graph more than once, one input has two outputs — so the graph is **not** the graph of a function.

## Summary

- A function gives **exactly one** output for each input (outputs may repeat).
- $f(a)$ is the output when the input is $a$: substitute $a$ for every $x$.
- The graph of $f$ is all points $(x, f(x))$.
- Vertical-line test: crossing more than once means not a function.
