<Callout type="why">
In 6.4–6.6 you **simplified expressions** — no equals sign, and the denominators had to stay. An **equation** is different: you may multiply both sides by the LCD and make every fraction disappear at once.
</Callout>

## Expression or equation?

| Expression | Equation |
|---|---|
| $\frac{x}{2} + \frac{x}{3}$ | $\frac{x}{2} + \frac{x}{3} = 5$ |
| Simplify: rewrite with the LCD, keep it | Solve: multiply both sides by the LCD |
| Answer: $\frac{5x}{6}$ | Answer: $x = 6$ |

## The variable in a denominator

When the variable appears in a denominator, start by noting which values are **not allowed**. After you solve, any answer equal to one of those values must be thrown out.

<StepReveal
  client:visible
  title="A solution that fails the check"
  problem="Solve: $\;\dfrac{x^2}{x - 1} = \dfrac{7x - 6}{x - 1}$"
  steps={[
    { show: '$x \\ne 1$', why: 'It would make the denominator $0$.' },

    { show: '$x^2 - 7x + 6 = 0 \\;\\Rightarrow\\; (x - 1)(x - 6) = 0$', why: '' },
    { show: '$x = 1$ or $x = 6$ — but $x = 1$ is not allowed. The solution is $x = 6$.', why: 'Multiplying by an expression that can be $0$ may add a false solution. Always check.' },
  ]}

<Callout type="warning" title="No solution is possible">
Sometimes every candidate fails the check — for example $\frac{x}{x - 2} = \frac{2}{x - 2} + 3$ leads only to $x = 2$, which is not allowed. Then the equation has **no solution**.
</Callout>

## Summary

- List the values that make a denominator $0$.
- Multiply **both sides** by the LCD; solve the equation that's left.
- Check every candidate. Reject any that make a denominator $0$.
