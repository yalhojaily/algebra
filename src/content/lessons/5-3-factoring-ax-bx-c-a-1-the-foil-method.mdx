<Callout type="why">
$3x^2 - 5x - 2$ doesn't start with a plain $x^2$, so the product–sum shortcut from 5.2 doesn't apply directly. But FOIL still describes how it was built: the **F**irst terms give $3x^2$, the **L**ast terms give $-2$, and **O**uter + **I**nner give $-5x$.
</Callout>

## Reverse FOIL

$$(\underline{\;\;}x + \underline{\;\;})(\underline{\;\;}x + \underline{\;\;})$$

1. Factor out any common factor first.
2. List the ways to make the **first** term $ax^2$ (factor pairs of $a$).
3. List the ways to make the **last** term $c$ (factor pairs of $c$, with signs).
4. Try combinations. Keep the one where **Outer + Inner = $bx$**.

<Callout type="tip" title="Narrow the search">
If $a$, $b$, $c$ have no common factor, then **neither binomial** can have a common factor. So $(2x + 4)$ is never a candidate when factoring $2x^2 + \ldots$ with no GCF — skip it.
</Callout>

When the leading coefficient is negative, factor out $-1$ first: $-2x^2 + x + 6 = -(2x^2 - x - 6) = -(2x + 3)(x - 2)$.

## Summary

- GCF (and $-1$) first.
- Try first-term pairs × last-term pairs; keep the one where Outer + Inner $= bx$.
- Always check by multiplying.
