<Callout type="why">
Problems with two unknowns are often easier with two variables than with one. With one variable you must squeeze every fact into a single equation; with two variables, **each fact becomes its own simple equation**, and the methods of 8.2 and 8.3 do the rest.
</Callout>

## The five steps, with two variables

1. **Familiarize.** Name the two unknowns, with units. Make a table and try a guess.
2. **Translate.** Write **two** equations — one for each fact. Very often one counts *how many* (tickets, liters, people) and the other counts *how much* (money, acid, distance).
3. **Solve** the system, by substitution or elimination.
4. **Check** in the original words — not just in your equations, because the equations themselves could be wrong.
5. **State** the answer in a sentence, with units.

## Total value

When items have different prices, one equation counts the **items** and the other counts the **money**. A table keeps them apart:

| | Number | Price (dollars) | Money (dollars) |
|---|---|---|---|
| Adult | $a$ | $10$ | $10a$ |
| Child | $c$ | $5$ | $5c$ |
| **Total** | $200$ | | $1600$ |

The "Number" column gives one equation and the "Money" column gives the other.

<StepReveal
  client:visible
  title="Tickets"
  problem="A theater sold $200$ tickets for a total of $1600$ dollars. Adult tickets cost $10$ dollars and child tickets $5$ dollars. How many of each were sold?"
  steps={[
    { show: '**Familiarize.** $a$ = adult tickets, $c$ = child tickets (see the table).', why: 'Guess $100$ of each: $1000 + 500 = 1500$ dollars — not enough, so there are more adult tickets.' },
    { show: '**Translate.** $\\;\\begin{cases} a + c = 200 & \\text{(tickets)} \\\\ 10a + 5c = 1600 & \\text{(dollars)} \\end{cases}$', why: '' },
    { show: '**Solve.** Multiply the first by $-5$: $-5a - 5c = -1000$. Add: $5a = 600$, so $a = 120$ and $c = 80$.', why: '' },
    { show: '**Check.** $120 + 80 = 200$ tickets ✓; $1200 + 400 = 1600$ dollars ✓', why: '' },
    { show: '**State.** $120$ adult tickets and $80$ child tickets were sold.', why: '' },
  ]}
/>

<QuickCheck

  question="In the ticket problem, which equation counts the **money**?"

## Mixtures

A mixture problem has the same structure: one equation for the **amount of liquid**, one for the **amount of the ingredient** (acid, salt, juice). The amount of ingredient is *percent × amount*: $20\%$ of $30$ L is $0.20 \times 30 = 6$ L of acid.

<StepReveal
  client:visible
  title="Mixing two solutions"
  problem="How many liters of a $10\%$ acid solution and of a $40\%$ acid solution must be mixed to get $30$ L of a $20\%$ solution?"
  steps={[
    { show: '**Familiarize.** $x$ = liters of $10\\%$, $y$ = liters of $40\\%$. The mixture has $0.20 \\times 30 = 6$ L of acid.', why: '$20\\%$ is closer to $10\\%$ than to $40\\%$, so expect **more** of the $10\\%$ solution.' },
    { show: '**Translate.** $\\;\\begin{cases} x + y = 30 & \\text{(liquid)} \\\\ 0.10x + 0.40y = 6 & \\text{(acid)} \\end{cases}$', why: '' },
    { show: '**Solve.** Multiply the acid equation by $10$: $x + 4y = 60$. Subtract the first equation: $3y = 30$, so $y = 10$ and $x = 20$.', why: '' },
    { show: '**Check.** $20 + 10 = 30$ L ✓; acid: $0.10(20) + 0.40(10) = 2 + 4 = 6$ L ✓', why: 'And as expected, more of the $10\\%$ solution.' },
    { show: '**State.** Mix $20$ L of the $10\\%$ solution with $10$ L of the $40\\%$ solution.', why: '' },
  ]}
/>

## Motion

With a current (or wind), the speeds add one way and subtract the other: going **with** the current the speed is $b + c$, **against** it $b - c$, where $b$ is the speed in still water. Use $d = rt$ for each trip.

<StepReveal
  client:visible
  title="Up and down the river"
  problem="A boat travels $48$ km downstream in $3$ hours and $24$ km upstream in $3$ hours. Find the boat's speed in still water and the speed of the current."
  steps={[
    { show: '**Familiarize.** $b$ = boat speed in still water, $c$ = current speed (km/h).', why: 'Downstream it goes $48 \\div 3 = 16$ km/h; upstream $24 \\div 3 = 8$ km/h. The boat speed should be halfway between.' },
    { show: '**Translate.** $\\;\\begin{cases} 3(b + c) = 48 \\\\ 3(b - c) = 24 \\end{cases}$', why: 'Distance = rate × time, once for each trip.' },
    { show: '**Solve.** Divide by $3$: $b + c = 16$ and $b - c = 8$. Add: $2b = 24$, so $b = 12$ and $c = 4$.', why: '' },
    { show: '**Check.** Downstream: $3(12 + 4) = 48$ ✓; upstream: $3(12 - 4) = 24$ ✓', why: '' },
    { show: '**State.** The boat goes $12$ km/h in still water; the current is $4$ km/h.', why: '' },
  ]}
/>

<QuickCheck

## Common mistakes

<Callout type="warning" title="Mixing up counts and values">
$a + c = 1600$ adds tickets and sets them equal to dollars. Keep one equation for *how many* and one for *how much*.
</Callout>

<Callout type="warning" title="Using percents as whole numbers">
The acid equation is $0.10x + 0.40y = 0.20(30)$. Writing $10x + 40y = 20$ mixes up scales. If you want whole numbers, multiply **every** term by $100$: $10x + 40y = 600$.
</Callout>

<Callout type="warning" title="Upstream and downstream backwards">
Downstream (with the current) is **faster**: $b + c$. Upstream is $b - c$. Quick test: downstream distance in the same time should be the larger one.
</Callout>

<Callout type="warning" title="Answering only half the question">
The problem asked for both numbers of tickets, or both liquids. Read the question again before you state the answer, and include units.
</Callout>

## Summary

- Two unknowns → two variables → one equation per fact.
- A table helps: one row per item, columns for amount, rate and total.
- Total value: one equation counts items, the other counts money.
- Mixtures: one equation for the liquid, one for the ingredient (percent × amount).
- Motion: speed with the current is $b + c$, against it $b - c$; distance = rate × time.
- Check the answer against the words of the problem.
