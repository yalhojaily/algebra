A ride requires riders to be at least 120 cm **and** at most 200 cm tall. A discount applies if you are under 12 **or** over 65. The same two numbers with "and" instead of "or" give a completely different set of people. This lesson makes those two little words precise.

## Intersection and union

- The **intersection** $A \cap B$ is the set of elements in **both** $A$ and $B$ — the overlap.
- The **union** $A \cup B$ is the set of elements in $A$, in $B$, or in both — everything together.
- The **empty set** $\varnothing$ has no elements.

$$\{1, 2, 3, 4\} \cap \{3, 4, 5\} = \{3, 4\}, \qquad \{1, 2, 3, 4\} \cup \{3, 4, 5\} = \{1, 2, 3, 4, 5\}.$$

A number satisfies "$P$ **and** $Q$" exactly when it is in the intersection of their solution sets, and "$P$ **or** $Q$" exactly when it is in the union. In mathematics, "or" includes "both".

## "And" and "or" on the number line

Shade each inequality on its own line, then combine: for **and**, keep only the overlap; for **or**, keep everything shaded.

<CompoundLine client:visible />

| Compound inequality | Solution |
|---|---|
| $x > -1$ **and** $x \le 4$ | $(-1, 4]$ — the overlap |
| $x < 1$ **and** $x > 3$ | $\varnothing$ — no overlap |
| $x < 1$ **or** $x > 3$ | $(-\infty, 1) \cup (3, \infty)$ — two pieces |
| $x < 5$ **or** $x > 2$ | $(-\infty, \infty)$ — every number is in at least one |

To type a union, use the letter U: `(-inf, -2) U [3, inf)`. For the empty set type `∅` or `no solution`.

## Conjunctions: "and"

A **conjunction** joins two inequalities with **and**. A double inequality like $-3 < 2x + 1 \le 7$ is a conjunction ($-3 < 2x + 1$ **and** $2x + 1 \le 7$). You can solve it in one go by doing the same thing to **all three parts**.

<StepReveal
  client:visible
  title="Double inequality"
  problem="Solve: $\;-3 < 2x + 1 \le 7$"
  steps={[
    { show: '$-4 < 2x \\le 6$', why: 'Subtract $1$ from all three parts.' },
    { show: '$-2 < x \\le 3$', why: 'Divide all three parts by $2$.' },
    { show: '$(-2, 3]$', why: 'Check $x = 0$: $-3 < 1 \\le 7$ ✓.' },
  ]}
/>

<StepReveal
  client:visible
  title="Dividing by a negative"
  problem="Solve: $\;-4 \le 2 - 3x < 11$"
  steps={[
    { show: '$-6 \\le -3x < 9$', why: 'Subtract $2$ from all three parts.' },
    { show: '$2 \\ge x > -3$', why: 'Divide all three parts by $-3$: **both** signs reverse.' },
    { show: '$-3 < x \\le 2$, that is $(-3, 2]$', why: 'Rewrite from smallest to largest. Check: $x = 2$ gives $2 - 6 = -4$, included ✓; $x = -3$ gives $11$, excluded ✓.' },
  ]}

## Disjunctions: "or"

A **disjunction** joins two inequalities with **or**. Solve each one separately and take the **union**.

<StepReveal
  client:visible
  title="Or"
  problem="Solve: $\;2x - 1 < -5\;$ or $\;3x + 2 \ge 8$"
  steps={[
    { show: '$x < -2$ or $x \\ge 2$', why: 'Solve each inequality on its own.' },
    { show: '$(-\\infty, -2) \\cup [2, \\infty)$', why: 'Everything that satisfies at least one of them. Note that it can\'t be written as one double inequality.' },
  ]}
/>

## In a real context

A *range* of allowed values — "between", "from … to", "at least … and less than …" — is a conjunction.

<StepReveal
  client:visible
  title="What do I need for a B?"
  problem="A B grade needs an average of at least $80$ and less than $90$. Your first three test scores are $85$, $78$ and $92$. What scores on the fourth test (out of $100$) give a B?"
  steps={[
    { show: '**Familiarize.** Let $x$ = the fourth score, $0 \\le x \\le 100$.', why: 'Guess $x = 80$: average $\\frac{335}{4} = 83.75$, a B. So $80$ is in the answer.' },
    { show: '**Translate.** $80 \\le \\dfrac{85 + 78 + 92 + x}{4} < 90$', why: '"At least 80 and less than 90" is a double inequality.' },
    { show: '**Solve.** $320 \\le 255 + x < 360 \\;\\Rightarrow\\; 65 \\le x < 105$', why: 'Multiply all three parts by $4$, subtract $255$.' },
    { show: '**Check.** $x = 65$: average $80$ ✓. But a score can\'t exceed $100$, so intersect with $[0, 100]$.', why: 'Every score up to $100$ keeps the average below $90$: $\\frac{355}{4} = 88.75$.' },
    { show: '**State.** Any score from $65$ to $100$: the set $[65, 100]$.', why: '' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Mixing up “and” and “or”">
"And" keeps only the **overlap**; "or" keeps **everything** shaded. $x < 1$ and $x > 3$ has no solution, but $x < 1$ or $x > 3$ has infinitely many.
</Callout>

<Callout type="warning" title="Reversing only one sign">
Dividing $-6 \le -3x < 9$ by $-3$ reverses **both** signs: $2 \ge x > -3$.
</Callout>

<Callout type="warning" title="Writing a disjunction as one interval">
$x < -2$ or $x \ge 2$ is $(-\infty, -2) \cup [2, \infty)$. Writing $(-2, 2)$ or "$2 \le x < -2$" describes the wrong set (or an impossible one).
</Callout>

<Callout type="warning" title="Ignoring the real-world limits">
A test score can't be $105$. Intersect your answer with the values that make sense.
</Callout>

## Summary

- **And** → intersection (overlap); **or** → union (everything shaded). "Or" includes "both".
- Solve a double inequality by working on all three parts; dividing by a negative reverses both signs.
- An "and" with no overlap is $\varnothing$; an "or" that covers everything is $(-\infty, \infty)$.
- In applications, a range of allowed values is a conjunction — and must respect real-world limits.
