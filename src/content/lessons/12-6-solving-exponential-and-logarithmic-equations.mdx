## Same base

If $b^M = b^N$, then $M = N$.

## Taking logarithms

When the bases can't be matched, take $\ln$ (or $\log$) of both sides and use the power rule to bring the exponent down.

## Logarithmic equations

Rewrite in exponential form (combining logs first if needed). Then **check**: each logarithm's argument must be positive.

<StepReveal
  client:visible
  title="Combine, then convert"

  steps={[
    { show: '$\\log[x(x - 3)] = 1$', why: 'Product rule.' },
    { show: '$x(x - 3) = 10^1$', why: 'Exponential form.' },

    { show: '$x = 5$ (reject $x = -2$: $\\log(-2)$ is undefined)', why: 'Always check.' },
  ]}

## Summary

- Same base: set exponents equal.
- Otherwise: take logs, use the power rule, divide.
- Log equations: condense, convert to exponential form, solve, check the domain.
