<Callout type="why">
$2^x = 8$ is easy: $x = 3$. But what about $2^x = 10$? We need a name for "the exponent on 2 that gives 10." That name is $\log_2 10$.
</Callout>

## The definition

$$\log_b a = c \quad\text{means}\quad b^c = a \qquad (b > 0,\ b \ne 1,\ a > 0)$$

**A logarithm is an exponent.** $\log_{10} a$ is written simply $\log a$ (the **common logarithm**).

## The logarithmic function

$f(x) = \log_b x$ is the inverse of $g(x) = b^x$. So its domain is $(0, \infty)$ — you can only take the logarithm of a positive number — and its range is all real numbers.

<Practice client:visible lesson="12.3" skill="domain" compact />

## Summary

- $\log_b a = c \iff b^c = a$.
- $\log a$ means $\log_{10} a$.
- $\log_b 1 = 0$, $\log_b b = 1$; logs of zero or negative numbers are undefined.
