## Solutions of a system

A **system of equations** is a set of equations that must all be true at the same time. A **solution** of a system in $x$ and $y$ is an ordered pair that makes **every** equation true.

## Solving by graphing

Graph both equations. Every point on a line is a solution of *that* equation, so a point on **both** lines — where they cross — is a solution of the system.

## One, none, or infinitely many

| The lines… | Solutions | The system is… |
|---|---|---|
| cross at one point | exactly one | **consistent**, **independent** |
| are parallel | none | **inconsistent** |
| are the same line | infinitely many | **consistent**, **dependent** |

<Callout type="tip" title="Spot it from the equations">
If the left side of one equation is a multiple of the other's, the lines have the same slope. Then the right sides decide: the same multiple means the **same line**; a different number means **parallel** lines.
</Callout>

## Summary

- A solution makes **all** equations true.
- Graphically: the intersection point(s) of the lines.
- Different slopes → one solution. Same slope → no solution (parallel) or infinitely many (same line).
