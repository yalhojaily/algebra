<Callout type="why">
Two phone plans: one costs $20 + 5t$ dollars after $t$ months, the other $35 + 2t$. When do they cost the same, and which is cheaper before and after? One equation can't answer that — you need **both equations at once**, a *system*. Its answer is the point where the two graphs cross.

## What is a solution of a system?

A **system of equations** is a set of equations that must all be true **at the same time**. A **solution** of a system in $x$ and $y$ is an ordered pair that makes **every** equation true. Making just one of them true is not enough.

## Why the answer is where the lines cross

The graph of an equation is the set of **all** points that make it true. So:

- a point on the first line makes the first equation true;
- a point on the second line makes the second equation true;
- a point on **both** lines — where they cross — makes **both** equations true. That is exactly a solution of the system.

## One solution, none, or infinitely many

Two lines in a plane can meet in only three ways:

| The lines… | Solutions | The system is… |
|---|---|---|
| cross at one point (different slopes) | exactly one | **consistent**, **independent** |
| are parallel (same slope, different intercepts) | none | **inconsistent** |
| are the same line | infinitely many | **consistent**, **dependent** |

**Consistent** means *at least one solution*. **Dependent** means the two equations say the same thing — one is a multiple of the other — so they describe the same line.

You can tell which case you have without graphing, by comparing the equations.

<StepReveal
  client:visible
  title="Parallel lines"
  problem="How many solutions does $\;\begin{cases} 2x + 3y = 6 \\ 4x + 6y = 5 \end{cases}$ have?"
  steps={[
    { show: 'Left sides: $4x + 6y = 2(2x + 3y)$', why: 'The second left side is $2$ times the first, so the lines have the same slope.' },
    { show: 'Right sides: $2 \\cdot 6 = 12 \\neq 5$', why: 'If the lines were the same, the right side would also be doubled.' },
    { show: 'Parallel lines: **no solution**. The system is inconsistent.', why: 'In words: $2x + 3y$ can\'t equal $6$ and $2.5$ at the same time.' },
  ]}
/>

<StepReveal
  client:visible
  title="The same line"
  problem="How many solutions does $\;\begin{cases} x - 2y = 4 \\ -3x + 6y = -12 \end{cases}$ have?"
  steps={[
    { show: '$-3(x - 2y) = -3x + 6y$ and $-3(4) = -12$', why: 'The whole second equation is $-3$ times the first — both sides.' },
    { show: 'Same line: **infinitely many solutions**. The system is consistent and dependent.', why: 'Every point on the line $x - 2y = 4$ is a solution, for example $(4, 0)$ and $(0, -2)$.' },
  ]}
/>

## In a real context

Comparing two plans is a system problem: each plan is one equation, and "costs the same" is where the lines cross.

<StepReveal
  client:visible
  title="Which phone plan?"
  problem="Plan A costs $20$ dollars to start plus $5$ dollars a month. Plan B costs $35$ dollars to start plus $2$ dollars a month. When do they cost the same, and which is cheaper after that?"
  steps={[
    { show: '**Familiarize.** Let $t$ = number of months and $C$ = total cost in dollars.', why: 'Guess: after $1$ month A costs $25$ and B costs $37$ (A cheaper). After $10$ months A costs $70$ and B costs $55$ (B cheaper). So they are equal somewhere in between.' },
    { show: '**Translate.** $\\;\\begin{cases} C = 20 + 5t \\\\ C = 35 + 2t \\end{cases}$', why: 'One equation per plan.' },
    { show: '**Solve.** $20 + 5t = 35 + 2t \\;\\Rightarrow\\; 3t = 15 \\;\\Rightarrow\\; t = 5$, and $C = 20 + 25 = 45$', why: 'Both expressions equal $C$, so they equal each other.' },
    { show: '**Check.** Plan A: $20 + 5 \\cdot 5 = 45$. Plan B: $35 + 2 \\cdot 5 = 45$ ✓', why: '' },
    { show: '**State.** Both plans cost 45 dollars after 5 months. After that Plan B is cheaper, because it adds less each month.', why: '' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Checking only one equation">
$(1, 0)$ makes $x + 2y = 1$ true, but it is **not** a solution of the system above, because $2x - y = 7$ is false there. Always check every equation.
</Callout>

<Callout type="warning" title="Trusting a graph without checking">
A hand-drawn graph can be off by half a unit. Read the intersection, then substitute it into both equations. If it fails, use algebra (8.2, 8.3).
</Callout>

<Callout type="warning" title="Mixing up “no solution” and “infinitely many”">
Same slope is not enough to decide. Compare the right sides too: same multiple → same line (infinitely many); different → parallel (none).
</Callout>

## Summary

- A solution of a system makes **all** of its equations true.
- Graphically, the solutions are the points the lines share: one point, none (parallel), or a whole line (the same line).
- Consistent = at least one solution; inconsistent = none; dependent = the equations describe the same line.
- Comparing two plans: each plan is an equation; "costs the same" is the intersection.

**Next, in 8.2:** an algebraic method, substitution, that finds the intersection exactly — even when it's at $\left(\frac{7}{3}, -\frac{1}{5}\right)$.
