<Callout type="why">
Before calculators, logarithm tables let scientists multiply huge numbers by **adding** their logarithms. The rules in this lesson are why that worked. They also explain why an earthquake with waves 100 times larger is only 2 points higher on the Richter scale — and they are the key tools for solving exponential equations in 12.6.
</Callout>

## The rules — and where they come from

For $M, N > 0$:

$$\log_b(MN) = \log_b M + \log_b N \qquad \log_b\frac{M}{N} = \log_b M - \log_b N \qquad \log_b M^p = p\log_b M$$

$$\log_b b^x = x \qquad b^{\log_b x} = x$$

**Why.** Logarithms are exponents, so each rule is an exponent law in disguise. Write $M = b^m$ and $N = b^n$, so $\log_b M = m$ and $\log_b N = n$. Then

- $MN = b^m b^n = b^{m+n}$, so $\log_b(MN) = m + n$ — **product → sum**;
- $\frac{M}{N} = b^{m-n}$, so $\log_b \frac{M}{N} = m - n$ — **quotient → difference**;
- $M^p = (b^m)^p = b^{mp}$, so $\log_b M^p = pm$ — **power → multiple**.

The last two rules say that $\log_b$ and "raise $b$ to a power" undo each other (12.2).

## Condensing

Run the rules backwards: **coefficients become powers first**, then combine sums (products) and differences (quotients).

<StepReveal
  client:visible
  title="Condense"
  problem="Write as a single logarithm: $\;3\log_2 x - \tfrac{1}{2}\log_2 y + \log_2 5$"
  steps={[
    { show: '$= \\log_2 x^3 - \\log_2 y^{1/2} + \\log_2 5$', why: 'Power rule first.' },
    { show: '$= \\log_2 \\dfrac{5x^3}{\\sqrt{y}}$', why: 'Plus terms go in the numerator, minus terms in the denominator.' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Rules that don't exist">
$\log(M + N) \ne \log M + \log N$, and $\dfrac{\log M}{\log N} \ne \log\dfrac{M}{N}$. Test with numbers if you're unsure — the table above does exactly that.
</Callout>

<Callout type="warning" title="Power rule on the wrong thing">
$\log x^2 = 2\log x$, but $(\log x)^2$ is different: the power is on the whole logarithm.
</Callout>

<Callout type="warning" title="Condensing in the wrong order">
Turn coefficients into powers **before** combining: $2\log x + \log y = \log(x^2y)$, not $\log(2xy)$.
</Callout>

## Summary

- Product → sum, quotient → difference, power → multiple: each is an exponent law, because logs are exponents.
- Expand: break the argument apart. Condense: powers first, then combine.
- $\log_b b^x = x$ and $b^{\log_b x} = x$.
- On log scales, multiplying the quantity **adds** to the level.
