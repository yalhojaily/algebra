<Callout type="why">
$\frac{2}{7} + \frac{3}{7} = \frac{5}{7}$, but $\frac{1}{2} + \frac{1}{3}$ needs a common denominator first. Rational expressions follow the same two rules — the only new work is factoring.
</Callout>

## Same denominator

$$\frac{A}{C} + \frac{B}{C} = \frac{A + B}{C}$$

Add the numerators, keep the denominator — then check whether the result simplifies.

<StepReveal
  client:visible
  title="Same denominator"
  problem="Add: $\;\dfrac{x - 2}{x^2 + 7x + 10} + \dfrac{2x + 17}{x^2 + 7x + 10}$"
  steps={[
    { show: '$= \\dfrac{3x + 15}{x^2 + 7x + 10}$', why: 'Add the numerators.' },
    { show: '$= \\dfrac{3(x + 5)}{(x + 2)(x + 5)}$', why: 'Factor the top and bottom.' },
    { show: '$= \\dfrac{3}{x + 2}$', why: 'Cancel $(x + 5)$.' },
  ]}
/>

## Opposite denominators

When the denominators are opposites, like $x - 4$ and $4 - x$, multiply one fraction by $\frac{-1}{-1}$:

$$\frac{3x}{x - 4} + \frac{5}{4 - x} = \frac{3x}{x - 4} + \frac{-5}{x - 4} = \frac{3x - 5}{x - 4}$$

## Different denominators

1. Factor the denominators and find the LCD.
2. Rewrite each fraction with the LCD (multiply top and bottom by the missing factors).
3. Add the numerators.
4. Simplify if possible.

  title="Different denominators"
  problem="Add: $\;\dfrac{3}{x + 2} + \dfrac{5}{x - 1}$"

/>

<QuickCheck
  client:visible
  question="What is the LCD for $\;\dfrac{2}{x} + \dfrac{5}{x + 1}$?"
  options={['$x(x + 1)$', '$2x + 1$', '$x + 1$', '$x^2 + 1$']}
  answer={0}
  explain="The denominators $x$ and $x + 1$ share no factor, so the LCD is their product."

/>

<Callout type="warning" title="Never add the denominators">
$\dfrac{3}{x + 2} + \dfrac{5}{x - 1} \ne \dfrac{8}{2x + 1}$. Check with $x = 0$: the left side is $\frac{3}{2} - 5 = -\frac{7}{2}$; the right side is $8$.
</Callout>

## Common mistakes

<Callout type="warning" title="Multiplying only the denominator">
To rewrite $\dfrac{3}{x + 2}$ with denominator $(x + 2)(x - 1)$, multiply the **numerator** by $(x - 1)$ too — that's what keeps the value the same.
</Callout>

<Callout type="warning" title="Forgetting to simplify">
After adding, factor the numerator: $\dfrac{3x + 15}{(x + 2)(x + 5)}$ simplifies to $\dfrac{3}{x + 2}$.
</Callout>

<Callout type="warning" title="Opposite denominators">
$\dfrac{5}{4 - x} = \dfrac{-5}{x - 4}$. The sign moves to the numerator when you flip the denominator.
</Callout>

## Summary

- Same denominator: add numerators, keep the denominator.
- Opposite denominators: multiply one fraction by $\frac{-1}{-1}$.
- Different denominators: factor → LCD → rewrite → add → simplify.
