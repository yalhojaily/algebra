<Callout type="why">
"What is the biggest…?" and "What is the smallest…?" are some of the most useful questions in business and engineering: the largest pen for a fixed amount of fence, the ticket price that earns the most, the stopping distance at a given speed. In 11.6 the function was given. Here you **build** it from the situation — and when it is quadratic, the answer is at its vertex.
</Callout>

## The plan

1. **Familiarize.** Decide what is being maximized or minimized, and choose one variable that controls it.
2. **Translate.** Write the quantity as a function of that one variable. If other quantities appear, use the facts of the problem to rewrite them in terms of it.
3. **Solve.** If the function is quadratic, its vertex is at $x = -\frac{b}{2a}$.
4. **Check** that the answer makes sense (lengths positive, within the allowed range).
5. **State** what was asked: the input (*which price?*), the output (*how much revenue?*), or both.

## Best price

When a price change affects how many items sell, revenue = price × number sold becomes quadratic.

<StepReveal
  client:visible
  title="Ticket price"
  problem="A theater sells $300$ tickets at $10$ dollars. Each $1$-dollar increase loses $20$ sales. What price maximizes revenue, and what is the revenue?"
  steps={[
    { show: '**Familiarize.** Let $x$ = number of $1$-dollar increases. Price $10 + x$; tickets sold $300 - 20x$.', why: '$x = 1$: $11 \\times 280 = 3080 > 3000$, so raising the price helps at first.' },
    { show: '**Translate.** $R(x) = (10 + x)(300 - 20x) = -20x^2 + 100x + 3000$', why: '' },
    { show: '**Solve.** $x = -\\dfrac{100}{2(-20)} = 2.5$, $\\;R(2.5) = 12.5 \\times 250 = 3125$', why: '' },
    { show: '**Check.** $R(2) = 12 \\times 260 = 3120$ and $R(3) = 13 \\times 240 = 3120$, both less ✓', why: 'Symmetric around $2.5$, as expected.' },
    { show: '**State.** A price of $12.50$ dollars gives the most revenue, $3125$ dollars.', why: '' },
  ]}
/>

## A minimum

<StepReveal
  client:visible
  title="The smallest product"
  problem="Two numbers differ by $8$. What is the smallest their product can be?"
  steps={[
    { show: '$P(x) = x(x + 8) = x^2 + 8x$', why: 'Let the numbers be $x$ and $x + 8$. $a > 0$: a minimum.' },
    { show: '$x = -\\dfrac{8}{2} = -4$, so the numbers are $-4$ and $4$', why: '' },
    { show: 'The smallest product is $-16$.', why: 'Check: $-3 \\cdot 5 = -15$ and $-5 \\cdot 3 = -15$, both larger ✓.' },
  ]}
/>

## Fitting a quadratic to data

Three points determine a quadratic $f(x) = ax^2 + bx + c$. Substituting each point gives three equations in $a$, $b$, $c$ — a system like those in 8.5. Then the model can predict.

<StepReveal
  client:visible
  title="Stopping distance"
  problem="A car needs $10$ m to stop at $20$ km/h, $28$ m at $40$ km/h and $54$ m at $60$ km/h. Fit $d(x) = ax^2 + bx + c$ and predict the stopping distance at $80$ km/h."
  steps={[
    { show: '$\\begin{cases} 400a + 20b + c = 10 \\\\ 1600a + 40b + c = 28 \\\\ 3600a + 60b + c = 54 \\end{cases}$', why: 'One equation per data point $(x, d)$.' },
    { show: 'Subtract: $1200a + 20b = 18$ and $2000a + 20b = 26$, so $800a = 8$', why: 'Eliminate $c$ twice, then $b$.' },
    { show: '$a = 0.01$, $b = 0.3$, $c = 0$: $\\;d(x) = 0.01x^2 + 0.3x$', why: 'Back-substitute. Check: $d(40) = 16 + 12 = 28$ ✓.' },
    { show: '$d(80) = 64 + 24 = 88$ m', why: 'Doubling the speed from $40$ to $80$ more than triples the distance — the $x^2$ term at work.' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="Answering the wrong coordinate">
"What price…?" wants the input; "what is the most revenue…?" wants the output. Many problems want both.
</Callout>

<Callout type="warning" title="Fencing a side that doesn't need it">
Against a wall, only three sides need fence: $2x + y = 60$, not $2x + 2y = 60$.
</Callout>

<Callout type="warning" title="Price and quantity both change">
Revenue is (new price) × (new quantity): $(10 + x)(300 - 20x)$. Changing only one of them gives a linear function with no maximum.
</Callout>

## Summary

- Write the quantity to optimize as a function of **one** variable, using the facts of the problem.
- Quadratic with $a < 0$: maximum at the vertex; $a > 0$: minimum. $x = -\frac{b}{2a}$, then evaluate if the output is asked for.
- Three points → three equations → $(a, b, c)$, a model you can use to predict.
