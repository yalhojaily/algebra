<Callout type="why">
Multiply $(x + 3)(x + 5)$ and you get $x^2 + 8x + 15$. Notice: $3 + 5 = 8$ and $3 \cdot 5 = 15$. That pattern is the whole trick to factoring these trinomials.
</Callout>

## The product–sum idea

$$(x + p)(x + q) = x^2 + (p + q)x + pq$$

So to factor $x^2 + bx + c$, look for two integers $p$ and $q$ with

$$p \cdot q = c \qquad \text{and} \qquad p + q = b.$$

Then $x^2 + bx + c = (x + p)(x + q)$.

<Callout type="tip" title="Sign shortcuts">
- $c > 0$: both numbers have the sign of $b$.
- $c < 0$: one positive, one negative; the one with the larger absolute value has the sign of $b$.
</Callout>

## Common factor first

Always check for a GCF before anything else. $2x^3 - 2x^2 - 24x = 2x(x^2 - x - 12) = 2x(x - 4)(x + 3)$.

<Practice client:visible lesson="5.2" skill="gcf" compact />

## Two variables

The same idea works for $x^2 + bxy + cy^2$ — just attach $y$ to each number:

$$x^2 - 2xy - 15y^2 = (x - 5y)(x + 3y)$$

## Prime trinomials

If **no** factor pair of $c$ adds to $b$, the trinomial cannot be factored using integers. It is **prime**. For example, $x^2 + x + 5$: the only pairs are $1, 5$ and $-1, -5$, with sums $6$ and $-6$ — never $1$.

<Practice client:visible lesson="5.2" skill="prime" compact />

## Summary

- $x^2 + bx + c = (x + p)(x + q)$ where $pq = c$ and $p + q = b$.
- Use the signs of $b$ and $c$ to know which pairs to try.
- Factor out a GCF first.
- No pair works → the trinomial is prime.
