<Callout type="why">
A store takes 20% off and you also have a 10-dollar coupon: which is applied first changes what you pay. That's a **composition** of two functions. Converting a temperature from Fahrenheit back to Celsius **undoes** a conversion — an **inverse** function. Logarithms, coming in 12.3, are defined exactly this way: as the inverses of exponential functions.
</Callout>

## Composite functions

$$(f \circ g)(x) = f(g(x))$$

Read it from the inside out: apply $g$ first, then feed the result to $f$. Order matters — usually $f(g(x)) \ne g(f(x))$.

<StepReveal
  client:visible
  title="Compose"
  problem="$f(x) = 3x - 1$, $g(x) = x^2$. Find $(f \circ g)(2)$, $(f \circ g)(x)$ and $(g \circ f)(x)$."
  steps={[
    { show: '$(f \\circ g)(2) = f(g(2)) = f(4) = 11$', why: 'Inside first: $g(2) = 4$.' },
    { show: '$(f \\circ g)(x) = f(x^2) = 3x^2 - 1$', why: 'Put $g(x)$ into $f$ wherever $f$ has $x$.' },
    { show: '$(g \\circ f)(x) = g(3x - 1) = (3x - 1)^2 = 9x^2 - 6x + 1$', why: 'The other order gives a different function.' },
  ]}
/>

<StepReveal
  client:visible
  title="Break a function apart"

## One-to-one functions — and why only they have inverses

An inverse must send each output **back** to the input it came from. That's only possible if no two inputs share an output. $f(x) = x^2$ sends both $2$ and $-2$ to $4$; given $4$, an "inverse" couldn't know which to return.

A function is **one-to-one** if different inputs always give different outputs. Graphically: no horizontal line crosses the graph more than once (the **horizontal-line test**). Only one-to-one functions have inverses.

<QuickCheck

  question="Which function is one-to-one?"
  options={['$f(x) = x^3$', '$f(x) = x^2$', '$f(x) = |x|$', '$f(x) = 5$']}
  answer={0}
  explain="Different inputs always give different cubes: every horizontal line crosses $y = x^3$ exactly once."
  wrong={{ 1: '$2$ and $-2$ both give $4$.', 2: '$3$ and $-3$ both give $3$.', 3: 'Every input gives $5$ — the most "not one-to-one" a function can be.' }}

## Finding a formula for the inverse

The inverse **swaps** the roles of input and output. So:

1. Replace $f(x)$ with $y$.
2. **Swap** $x$ and $y$.
3. Solve for $y$.
4. Replace $y$ with $f^{-1}(x)$, and check: $f(f^{-1}(x)) = x$.

<StepReveal
  client:visible
  title="A linear function"
  problem="Find $f^{-1}(x)$ for $\;f(x) = 2x + 3$."
  steps={[
    { show: '$y = 2x + 3$', why: '' },
    { show: '$x = 2y + 3$', why: 'Swap $x$ and $y$.' },
    { show: '$y = \\dfrac{x - 3}{2}$', why: 'Solve for $y$. In words: $f$ doubles and adds $3$; $f^{-1}$ subtracts $3$ and halves — the steps undone in reverse order.' },
    { show: '$f^{-1}(x) = \\dfrac{x - 3}{2}$', why: 'Check: $f(f^{-1}(x)) = 2 \\cdot \\frac{x - 3}{2} + 3 = x$ ✓' },
  ]}
/>

<StepReveal
  client:visible
  title="A cubic"
  problem="Find $f^{-1}(x)$ for $\;f(x) = x^3 - 1$."
  steps={[
    { show: '$x = y^3 - 1 \\;\\Rightarrow\\; y^3 = x + 1$', why: 'Swap, then isolate $y^3$.' },
    { show: '$f^{-1}(x) = \\sqrt[3]{x + 1}$', why: 'Check: $f(\\sqrt[3]{x + 1}) = (x + 1) - 1 = x$ ✓' },
  ]}
/>

<Callout type="warning" title="f⁻¹ is not 1/f">
The $-1$ in $f^{-1}$ is not an exponent. $f^{-1}$ is the function that undoes $f$, not the reciprocal $\frac{1}{f(x)}$.
</Callout>

## The graph of an inverse

If $(a, b)$ is on the graph of $f$, then $f^{-1}(b) = a$, so $(b, a)$ is on the graph of $f^{-1}$. Swapping coordinates reflects a point across the line $y = x$ — so the graph of $f^{-1}$ is the **mirror image** of the graph of $f$ in $y = x$.

## Common mistakes

<Callout type="warning" title="Composing in the wrong order">
$(f \circ g)(x) = f(g(x))$: $g$ acts **first**, even though $f$ is written first.
</Callout>

<Callout type="warning" title="Forgetting to swap">
Solving $y = 2x + 3$ for $x$ gives the right formula with the letters in the wrong roles. Swap $x$ and $y$, then solve for $y$.
</Callout>

<Callout type="warning" title="Inverting a function that isn't one-to-one">
$y = x^2$ has no inverse on all real numbers; $\pm\sqrt{x}$ is not a function. (Restricting to $x \ge 0$ fixes it: then $f^{-1}(x) = \sqrt{x}$.)
</Callout>

## Summary

- $(f \circ g)(x) = f(g(x))$ — inside first; order matters.
- Only one-to-one functions (horizontal-line test) have inverses, because an inverse must send each output back to one input.
- Find $f^{-1}$ by swapping $x$ and $y$ and solving; check that $f(f^{-1}(x)) = x$.
- The graph of $f^{-1}$ is the graph of $f$ reflected in $y = x$.
