<Callout type="why">
Fold a sheet of paper in half 10 times and it is $2^{10} = 1024$ sheets thick. Money in a bank, bacteria in a dish and the number of people who've seen a viral video all grow this way: by **multiplying** at a steady rate, not by adding. Exponential functions describe that kind of change — and its mirror image, decay, as in medicine leaving the bloodstream or a car losing value.
</Callout>

## Adding versus multiplying

Compare $f(x) = 2x$ and $g(x) = 2^x$:

| $x$ | $0$ | $1$ | $2$ | $3$ | $4$ | $10$ |
|---|---|---|---|---|---|---|
| $2x$ (add $2$ each step) | $0$ | $2$ | $4$ | $6$ | $8$ | $20$ |
| $2^x$ (multiply by $2$ each step) | $1$ | $2$ | $4$ | $8$ | $16$ | $1024$ |

A linear function adds the same amount at each step. An exponential function **multiplies** by the same factor: $b^{x+1} = b \cdot b^x$. Early on the difference is small; soon it is enormous.

## Exponential functions

The function $f(x) = b^x$, with $b > 0$ and $b \ne 1$, is an **exponential function** with base $b$. (If $b = 1$ it is the constant $1$; if $b < 0$, values like $(-2)^{1/2}$ aren't real.)

- $f(0) = b^0 = 1$, so the graph passes through $(0, 1)$. For $f(x) = a \cdot b^x$ the $y$-intercept is $(0, a)$.
- $b^x > 0$ for every $x$: the graph stays above the $x$-axis and gets closer and closer to it — the $x$-axis is a horizontal **asymptote**.
- If $b > 1$ the function **grows**; if $0 < b < 1$ it **decays**.
- Domain: all real numbers. Range: $(0, \infty)$.

## Compound interest

If $P$ dollars earns annual rate $r$, compounded $n$ times per year, then each period multiplies the balance by $1 + \frac{r}{n}$, and there are $nt$ periods in $t$ years:

$$A = P\left(1 + \frac{r}{n}\right)^{nt}$$

<StepReveal
  client:visible
  title="Monthly compounding"
  problem="$1000$ dollars is invested at $6\%$ compounded monthly. How much is there after $5$ years?"
  steps={[
    { show: '$P = 1000,\\ r = 0.06,\\ n = 12,\\ t = 5$', why: 'Write the rate as a decimal.' },
    { show: '$A = 1000\\left(1 + \\dfrac{0.06}{12}\\right)^{12 \\cdot 5} = 1000(1.005)^{60}$', why: 'Each month multiplies by $1.005$; there are $60$ months.' },
    { show: '$\\approx 1000(1.348850) \\approx 1348.85$ dollars', why: 'Simple interest would give only $1300$: interest earns interest.' },
  ]}
/>

## Common mistakes

<Callout type="warning" title="3 · 2ˣ is not 6ˣ">
The exponent applies only to the base right before it: $3 \cdot 2^2 = 12$, while $6^2 = 36$.
</Callout>

<Callout type="warning" title="Percent as a whole number">
In $A = P(1 + \frac{r}{n})^{nt}$, $6\%$ is $r = 0.06$, not $6$.
</Callout>

<Callout type="warning" title="The wrong exponent">
Compounded monthly for $5$ years means $nt = 60$ periods, not $5$ or $12$.
</Callout>

## Summary

- Linear change adds; exponential change multiplies: $b^{x+1} = b \cdot b^x$.
- $f(x) = a \cdot b^x$: growth if $b > 1$, decay if $0 < b < 1$; $y$-intercept $(0, a)$; the $x$-axis is an asymptote.
- $A = P\left(1 + \frac{r}{n}\right)^{nt}$: $nt$ periods, each multiplying by $1 + \frac{r}{n}$.
