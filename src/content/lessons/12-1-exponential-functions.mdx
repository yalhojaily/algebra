## Exponential functions

The function $f(x) = b^x$, with $b > 0$ and $b \ne 1$, is an **exponential function** with base $b$.

- $f(0) = b^0 = 1$, so the graph passes through $(0, 1)$.
- $b^x > 0$ for every $x$: the graph stays above the $x$-axis, which is a horizontal **asymptote**.
- Domain: all real numbers. Range: $(0, \infty)$.

## Compound interest

If $P$ dollars is invested at annual rate $r$, compounded $n$ times per year, then after $t$ years the amount is

$$A = P\left(1 + \frac{r}{n}\right)^{nt}$$

<Practice client:visible lesson="12.1" skill="interest" compact />

## Summary

- $f(x) = b^x$: growth if $b > 1$, decay if $0 < b < 1$.
- Passes through $(0, 1)$; the $x$-axis is an asymptote.
- $A = P(1 + \frac{r}{n})^{nt}$.
