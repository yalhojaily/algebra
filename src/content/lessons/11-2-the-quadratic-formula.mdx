<Callout type="why">
Completing the square works every time, but it is the same sequence of steps every time. Do those steps **once**, with letters instead of numbers, and you get a formula you can simply plug into — one of the most used formulas in all of mathematics, science and engineering.
</Callout>

## Where the formula comes from

Complete the square on the general equation $ax^2 + bx + c = 0$ (with $a \ne 0$), exactly as in 11.1:

    { show: '$x^2 + \\dfrac{b}{a}x = -\\dfrac{c}{a}$', why: 'Divide by $a$; move the constant.' },
    { show: '$x^2 + \\dfrac{b}{a}x + \\dfrac{b^2}{4a^2} = \\dfrac{b^2}{4a^2} - \\dfrac{c}{a}$', why: 'Add $\\left(\\frac{b}{2a}\\right)^2$ to both sides.' },

    { show: '$x + \\dfrac{b}{2a} = \\pm\\dfrac{\\sqrt{b^2 - 4ac}}{2a}$', why: 'Principle of square roots; $\\sqrt{4a^2} = 2|a|$, and the $\\pm$ covers its sign.' },
    { show: '$x = \\dfrac{-b \\pm \\sqrt{b^2 - 4ac}}{2a}$', why: 'Subtract $\\frac{b}{2a}$.' },
  ]}

## The formula

The solutions of $ax^2 + bx + c = 0$ (with $a \ne 0$) are

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

The whole numerator, $-b \pm \sqrt{\ldots}$, is divided by $2a$.

<StepReveal
  client:visible
  title="Use the formula"
  problem="Solve: $\;2x^2 + 3x - 1 = 0$"
  steps={[
    { show: '$a = 2,\\ b = 3,\\ c = -1$', why: 'Identify the coefficients — including signs.' },
    { show: '$x = \\dfrac{-3 \\pm \\sqrt{9 - 4(2)(-1)}}{2(2)} = \\dfrac{-3 \\pm \\sqrt{17}}{4}$', why: '$-4ac = -4(2)(-1) = +8$, so the radicand is $9 + 8 = 17$.' },
    { show: '$x \\approx 0.28$ or $x \\approx -1.78$', why: 'Approximations, if needed: $\\sqrt{17} \\approx 4.123$.' },
  ]}
/>

<StepReveal
  client:visible
  title="Simplify the result"
  problem="Solve: $\;x^2 - 4x - 1 = 0$"
  steps={[
    { show: '$x = \\dfrac{4 \\pm \\sqrt{16 + 4}}{2} = \\dfrac{4 \\pm \\sqrt{20}}{2}$', why: '$-b = -(-4) = 4$.' },
    { show: '$= \\dfrac{4 \\pm 2\\sqrt{5}}{2} = 2 \\pm \\sqrt{5}$', why: 'Simplify $\\sqrt{20} = 2\\sqrt{5}$, then divide **both** terms by $2$.' },
  ]}
/>

<Callout type="tip" title="Typing the answer">
Type `(-3 +- sqrt(17))/4`, or list both: `(-3 + sqrt(17))/4, (-3 - sqrt(17))/4`. The parentheses around the numerator matter.
</Callout>

## Standard form first

The formula needs the equation in the form $ax^2 + bx + c = 0$. Move everything to one side first.

## Complex solutions

When $b^2 - 4ac < 0$, the square root is imaginary and the solutions are complex conjugates $p \pm qi$.

<StepReveal
  client:visible
  title="Complex solutions"
  problem="Solve: $\;x^2 - 2x + 5 = 0$"
  steps={[
    { show: '$x = \\dfrac{2 \\pm \\sqrt{4 - 20}}{2} = \\dfrac{2 \\pm \\sqrt{-16}}{2}$', why: '' },
    { show: '$= \\dfrac{2 \\pm 4i}{2} = 1 \\pm 2i$', why: '$\\sqrt{-16} = 4i$.' },

## In a real context

The formula shines when the numbers in a real problem don't factor.

<StepReveal
  client:visible
  title="A rug"

  steps={[
    { show: '**Familiarize.** Let $w$ = width (ft); the length is $w + 7$.', why: 'Guess $w = 4$: area $4 \\cdot 11 = 44$, a bit small. So $w$ is a little more than $4$.' },

    { show: '**State.** The rug is about $4.26$ ft wide (and $11.26$ ft long).', why: '' },

## Common mistakes

<Callout type="warning" title="Sign of −b">
If $b = -4$, then $-b = 4$. Write the substitution with parentheses: $-(-4)$.
</Callout>

<Callout type="warning" title="Dividing only the root by 2a">
$x = -b \pm \frac{\sqrt{b^2 - 4ac}}{2a}$ is wrong. The **whole** numerator is over $2a$.
</Callout>

<Callout type="warning" title="−4ac with a negative c">
For $c = -1$: $-4(2)(-1) = +8$. Two negatives make a positive.
</Callout>

<Callout type="warning" title="Not in standard form">
In $3x^2 - x = 4$, $c$ is not $4$. Move everything to one side first.
</Callout>

## Summary

- Completing the square on $ax^2 + bx + c = 0$ gives $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.
- Write the equation in standard form, identify $a$, $b$, $c$ with their signs, then substitute.
- Simplify the radical and divide every term by the common factor.
- A negative $b^2 - 4ac$ gives complex conjugate solutions.
